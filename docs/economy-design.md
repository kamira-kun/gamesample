# 経済システム設計

ソロでもトレードリーグらしい経済を味わえるように、仮想の市場参加者をシミュレートする。

- フェーズ1：**クラフト通貨の取引所**（1〜9 節）
- フェーズ2：**ユニーク・レア装備の取引**（10 節）
- フェーズ3：**NPC の買取依頼**（11 節）
- フェーズ4：**出品検索**（12 節、#65）

## 決定事項

| 項目 | 決定 |
|---|---|
| 基軸通貨 | 混沌の残光（相場はすべて「c」建て。混沌自身は常に 1c） |
| 灰燼の欠片 | 取引所では売買できない NPC 専用のお金。取引手数料の支払いに使う |
| 時間の進め方 | プレイ量で進む。現実の時計は使わない |
| 固定価格の通貨販売 | 割高にして残す（相場の上限＝安全弁） |
| 相場の流れ | シーズンIDをシードにして、流行・出来事を固定。細かい値動きはランダム |

## 1. 時間

- **市場ティック**：マップを1つ完了してハイドアウトに戻るたびに 1 ティック進む。
- **市場日**：10 ティック = 1 市場日。シーズンの段階や価格推移グラフはこの単位で数える。
- 現実の日付はシーズンの開催期間の判定だけに使う（今の仕組みのまま）。

## 2. 価格のモデル

通貨ごとに **目標価格 P\*** と **現在価格 P** を持つ。

```
P* = 基本価値 × シーズン段階補正(市場日) × 出来事補正(市場日)
```

### 基本価値
`CURRENCIES` の既存の `value` を混沌の value（25）で割った値。

| 通貨 | value | 基本価値 |
|---|---|---|
| 変容の結晶 | 5 | 0.20c |
| 浄化の雫 | 8 | 0.32c |
| 羅針の欠片 | 12 | 0.48c |
| 鍛錬の砥石 | 15 | 0.60c |
| 昇華の焔 | 20 | 0.80c |
| 混沌の残光 | 25 | 1c（固定） |
| 神秘の核 | 80 | 3.2c |

### シーズン段階補正
通貨ごとに `early`（シーズン開始時）と `late`（成熟後）の倍率を持ち、市場日 0〜30 の間で滑らかに移る。

```
段階補正 = lerp(early, late, smoothstep(0, 30, 市場日))
```

- 安い通貨（変容・浄化）：early 1.5 → late 0.7（序盤は需要があり、だんだん余る）
- 中くらいの通貨（砥石・昇華・羅針）：early 1.2 → late 0.9
- 高い通貨（神秘）：early 0.8 → late 1.6（終盤ほど高騰）
- スタンダードリーグは常に `late`（成熟した市場）。

### 毎ティックの値動き

```
P ← P + 0.15 × (P* − P) + 0.03 × P × N(0, 1)
P は 0.25 × 基本価値 〜 4 × 基本価値 の範囲に収める
```

目標価格に引き戻されつつ、少し揺れる。

### プレイヤーの売買による影響
通貨ごとに **市場の厚み D**（変容 300、浄化・羅針・砥石 150、昇華 100、神秘 30）を持つ。

```
q 個売る： P ×= (1 − 0.5 × q / D)
q 個買う： P ×= (1 + 0.5 × q / D)
```

動いた価格は、上の引き戻しで数ティックかけて元に戻る。
大量に売りさばくと値崩れするので、少しずつ売るか、指値で待つほうが得になる。

## 3. 売買の種類

### 成行（すぐに成立）
- 買値 = P × (1 + スプレッド/2)、売値 = P × (1 − スプレッド/2)
- スプレッド：変容・浄化 6%、その他 8%、神秘 12%
- 1回の注文の途中でも価格が動く（1個ずつ影響を積み上げて計算する）

### 指値（出品して待つ）
- 値段と数量を決めて出品する。スプレッドはかからない。
- 売り注文の値段が現在価格以下なら、その場で成行として成立する。
- それより高い場合は、毎ティック一部だけ成立する。

```
1ティックで成立する割合 = 0.3 × exp(−8 × (指値 / P − 1))
```

| 指値 | 1ティックで成立する割合 |
|---|---|
| 現在価格 +5% | 約 20% |
| +20% | 約 6% |
| +50% | 約 0.5% |

- 買い注文も同じ式を左右反対にして使う。
- 同時に出せる注文は 8 件まで。50 ティック経っても残っている分はスタッシュに戻す。
- 成立した結果は、ハイドアウトに戻ったときにまとめて通知する（「マップから戻ったら売れていた」体験）。

### 手数料（灰燼の欠片の使い道）
```
手数料（灰燼） = max(5, ceil(取引額(c) × 8))
```
成行・指値どちらも、成立した時点で支払う。払えない場合は注文できない。

## 4. 商人の固定価格販売（相場の上限）

```
商人の販売価格（灰燼） = round(相場(c) × 250 × discount)
```
- 混沌の残光は 250 灰燼（今は 100）。
- 相場が上がれば商人の値段も上がるが、灰燼でいつでも買える＝極端な高騰は起きない。
- 商人は通貨を買い取らない。灰燼→通貨の一方通行なので、行ったり来たりで稼ぐことはできない。

## 5. シーズンの出来事（シード固定）

シーズンIDのハッシュをシードにして、シーズンごとに 3〜5 件の出来事を作る。

```
{ 通貨, 倍率 (0.6〜1.8), 開始する市場日, 続く日数 (3〜8) }
```
例：「鍛錬の砥石ブーム：市場日 5〜12 の間、需要 ×1.4」

- 同じシーズンなら誰が遊んでも同じ流れになる（テストもしやすい）。
- ハイドアウトの **相場掲示板** で、始まる 1 日前に予告し、開催中は表示し続ける。
- フェーズ2で、ユニークのタグ（召喚・火など）を対象にした流行に広げる。

## 6. 保存

リーグ共有スタッシュと同じく **リーグごと** に保存する。

```
market = {
  tick: int,
  prices: { 通貨キー: P },
  orders: [ { id, side: "buy"|"sell", k, qty, filled, limit, placed_tick } ],
  history: { 通貨キー: [直近 60 市場日の終値] },
  pending: [ 次にハイドアウトへ戻ったときに出す通知 ],
}
```

- シーズン終了で移行するとき、そのリーグの相場は捨てる。残っていた注文は、預けていた通貨をスタンダードのスタッシュに返す。
- 新しいシーズンは、すべての通貨を `early` の目標価格から始める。

## 7. 画面

ハイドアウトに **取引所** の窓口を置く（商人の画面のタブにしてもよい）。

- **相場一覧**：通貨ごとに現在価格、前日比、直近 14 市場日のミニグラフ
- **売買**：成行／指値の切り替え、数量、指値、成立見込み（「約 N ティックで売れそう」）、手数料
- **注文一覧**：出している注文の進み具合と取り消しボタン
- **相場掲示板**：開催中・予告中の出来事

## 8. 稼ぎすぎの防止の確認

- 成行で買ってすぐ売る：スプレッド＋影響＋手数料で 10% 以上損をする。
- 商人で買って取引所で売る：250 灰燼で買った 1c を売っても 1c 弱にしかならず、灰燼を通貨に換えるだけで得はない。
- 同じ物を大量に売る：値崩れして、まとめて売るほど 1 個あたりが安くなる。

## 9. テスト（スモークテストに追加）

- プレイヤーが何もしないで 300 ティック進めても、全通貨が 0.25〜4 × 基本価値の範囲に収まる。
- 同じシーズンIDなら、出来事の一覧が毎回同じになる。
- 成行で買ってすぐ売ると、通貨が減る。
- 指値の売り注文が、何ティックか後に成立して、混沌と通知が増える。
- シーズン移行で、残っていた注文の通貨がスタンダードのスタッシュに戻る。

## 10. 装備の取引（フェーズ2）

取引所の「装備」ページで、**レアとレジェンド（ユニーク）** の装備を混沌で売り買いする。
装備の値段はすべて **整数の混沌**。ノーマル・マジックは今まで通り商人に売る。

### 装備の相場 V
```
V = 基本の値打ち × シーズン段階補正 × 流行補正
```
- **ユニーク**：名前から決まる人気（シードは名前なので、どのリーグでも同じ）
  - 並（75%）0.3〜1c、人気（20%）1.5〜4c、垂涎（5%）6〜15c
  - × (0.75 + 0.5 × 固定能力値の出目の良さ) × (0.8 + 0.4 × min(アイテムレベル / 40, 1))
- **レア**：能力値ごとの重み × 出目の良さ² の合計 s を使う
  - (0.1 + 0.3 × s) × (0.6 + アイテムレベル / 25)
  - 重み：移動速度 1.5、エネルギー 1.2、ライフ・ダメージ・攻撃速度・詠唱速度 1.0、クリティカルダメージ・スキルダメージ 0.9、属性ダメージ・クリティカル率 0.8、その他 0.4
- 出目の良さ：その能力値の範囲（アイテムレベルで伸びた分を戻したもの）の中で、どこまで高く出たか（0〜1）
- シーズン段階補正：レア 1.4 → 0.8、ユニーク 1.3 → 0.9（通貨と同じく市場日 0〜30 で移る。スタンダードは常に後者）

### タグと流行
装備には、正の能力値やユニークの効果文から **タグ** が付く：火炎・冷気・雷・召喚・攻撃・呪文・ライフ・クリティカル・速度。
シーズンIDをシードにして、シーズンごとに 2〜3 件の **流行** を作る（スタンダードにはない）。
```
{ タグ, 倍率（流行 1.3〜2.0 が 7 割、不人気 0.6〜0.8 が 3 割）, 開始する市場日, 続く日数 (4〜8) }
```
開催中はそのタグを持つ装備の V に倍率が掛かる。相場掲示板で前日に予告する。

### 出品（売る）
- 所持品のレア・ユニークに希望価格（混沌）を付けて出品する。最大 8 件、50 ティックで期限切れ。
- **出品手数料** `max(5, ceil(希望価格 × 8))` 灰燼を出品時に払う（戻らない。出品の乱発を防ぐ）。
- 1 ティックで売れる確率：
```
min(0.6, 0.25 × exp(−6 × (希望価格 / V − 1)))
```
| 希望価格 | 1 ティックで売れる確率 |
|---|---|
| V | 25% |
| V × 1.2 | 約 7.5% |
| V × 1.5 | 約 1.2% |

- 売れたら混沌を受け取り、帰還時に通知する。期限切れや、所持品が一杯のときの取り下げは **受け取り箱** に入る。
- **業者に即売り**：その場で `floor(V × 0.6)` 混沌で引き取ってもらえる（1 混沌にならない物は断られる）。

### ほかの冒険者の出品（買う）
- 常に 10 件並ぶ。アイテムレベルは隠れ家のレベル。4 割がユニーク、6 割はレアを 4 つ作って一番良いもの。
- 値段は `ceil(V × 0.95〜1.5)`（最低 1）。買うときに手数料 `max(5, ceil(値段 × 8))` 灰燼がかかる。
- 毎ティック 12% の確率でほかの人に買われて消え、30 ティックで取り下げられる。減った分はすぐ補充される。

## 11. NPC の買取依頼（フェーズ3）

取引所の「買取依頼」ページ。NPC が条件付きで装備を求め、合う装備を納品すると報酬の混沌をもらえる（手数料なし）。

- 同時に 3 件まで。毎ティック、空きがあれば 50% の確率で新しい依頼が来る（通知あり）。30 ティックで締め切り。
- 依頼の種類
  - **能力値つきの装備**（65%）：「指輪（マジックかレア）で『最大ライフ +N 以上』」。N は隠れ家のレベルで出目が真ん中の値。
    報酬 `clamp(ceil(0.5 + (1 + レベル / 20) × 能力値の重み), 1, 10)` 混沌。
  - **タグつきのユニーク**（35%）：「召喚タグのユニーク（どれでも）」。報酬 `(2〜4) × そのタグの流行補正` 混沌。
- 所持品の中で条件に合う物のうち、相場が一番安い物を納品する（画面でどれを渡すか表示する）。
- マジック装備でも条件を満たせば受け取ってもらえるので、変容・研ぎ石でのクラフトに目的ができる。

## 12. 装備の保存とシーズン移行

`market` に次を足す（リーグごと）。
```
ilvl: int                 # ほかの冒険者の出品を作るレベル（隠れ家のレベル）
listings: [ { id, item, ask, placed_tick } ]
offers:   [ { id, item, price, placed_tick } ]
requests: [ { id, kind: "affix"|"unique", slot, k, need, tag, reward, who, placed_tick } ]
held:     [ item ]        # 受け取り箱
```
シーズン終了で相場を捨てるとき、出品中の装備と受け取り箱の装備は、スタンダードのスタッシュに
「<シーズン名> 取引所」というタブを足して移す。ほかの冒険者の出品と依頼は捨てる。

## 13. 稼ぎすぎの防止の確認（装備）

- ほかの冒険者の出品を買ってすぐ出し直す：一番安くても 0.95 V で、買うときと出品するときの手数料（合わせて取引額の約 6.4%）と待ち時間がかかるので、ほとんど得にならない。業者に売ると 0.6 V。
- 業者に即売りは V の 6 割なので、待てる人は出品したほうが得。
- 依頼の報酬は相場より高いが、同時に 3 件・締め切りつきなので、稼ぎの柱にはならない。

## API（`godot/scripts/market.gd` の `Market`）

相場の状態は `Profiles.data.market[リーグ]` にあり、リーグ共有スタッシュと一緒に保存される。
`league` は `main.league()`、`wallet` は `player.cur`（通貨キー → 個数）を渡す。
`k` は取引所で扱う通貨キー（`Market.keys()`。灰燼と混沌は含まない）、`side` は `"buy"` か `"sell"`。
失敗を返す関数は、成功なら `""`、失敗ならプレイヤーに見せる理由の文字列を返す。

### 参照
| 関数 | 返り値 |
|---|---|
| `Market.keys()` | 取引できる通貨キーの配列（`CURRENCIES` の順） |
| `Market.price(league, k)` | 現在価格（c）。`"chaos"` は常に 1.0 |
| `Market.day_change(league, k)` | 前の市場日の終値からの変化率（0.05 = +5%）。終値がまだなければ 0 |
| `Market.history(league, k, days := 14)` | 直近 `days` 市場日の終値（古い順） |
| `Market.target(league, k, day)` | 市場日 `day` の目標価格 P* |
| `Market.day(Market.state(league))` | 今の市場日（小数。tick / 10） |
| `Market.events(league)` | シーズンの出来事 `{k, mult, start, days}` の配列（スタンダードは空） |
| `Market.board(league)` | 相場掲示板用：開催中・翌日開始の出来事。各要素に `state`（`"active"`/`"soon"`）と `text` を追加 |
| `Market.event_text(e)` | 出来事の説明文 |
| `Market.orders(league)` | 出している注文 `{id, side, k, qty, filled, limit, placed_tick, left, ticks_left, ...}` |
| `Market.fee(value_c)` | 取引額 `value_c`（c）の手数料（灰燼） |

### 見積もり
| 関数 | 返り値 |
|---|---|
| `Market.quote(league, k, side, qty)` | 成行の見積もり `{total, avg, chaos, fee, end_price}`。`chaos` は実際に払う／受け取る混沌（買いは切り上げ、売りは切り捨て） |
| `Market.fill_rate(league, k, side, limit)` | 指値が 1 ティックで成立する割合（1.0 ならその場で成行として成立） |
| `Market.limit_estimate(league, k, side, limit, qty)` | `{rate, ticks, fee, cost, instant}`。`ticks` は全部成立するまでの目安（-1 は期限の 50 ティック内には難しい）、`cost` は預ける混沌（買い）か通貨の個数（売り） |

### 操作
| 関数 | 内容 |
|---|---|
| `Market.market_trade(league, k, side, qty, wallet)` | 成行で売買する。手数料も `wallet` の灰燼から払う |
| `Market.place_limit(league, k, side, limit, qty, wallet)` | 指値を出す。売りは通貨、買いは混沌と、全量分の手数料を預ける（成立分の手数料を差し引いて、残りは閉じるときに返す）。現在価格を越える指値は成行として成立 |
| `Market.cancel(league, id, wallet)` | 注文を取り消し、預けた分を `wallet` に返す。見つからなければ false |
| `Market.take_notes(league)` | ハイドアウト帰還時に出す通知（文字列の配列）を取り出して消す |
| `Market.tick(league, wallet)` | 1 ティック進める（`main.complete_map` が呼ぶ。UI からは呼ばない） |

### 補足
- 指値の成立・期限切れの返却は、ティックの時点で `wallet`（そのとき帰還したキャラクターの所持通貨）に入る。
- シーズン終了時（`Profiles.migrate`）は相場を捨て、注文が預かっていた通貨と未使用の手数料を
  `Profiles.stash_cur("standard")` に入れる。スタンダードのキャラクターを読み込むと
  `Profiles.take_stash_cur` で所持通貨に移り、メッセージが出る。
- `Market.tick` は最後に `Trade.tick` を呼び、装備の出品・ほかの冒険者の出品・依頼も同じティックで進む。

## API（`godot/scripts/trade.gd` の `Trade`、フェーズ2・3）

状態は同じ `Market.state(league)` の中にある。`bag` は所持品の配列（`player.bag`）、`i` はその番号。
失敗を返す関数は、成功なら `""`、失敗ならプレイヤーに見せる理由を返す。

| 関数 | 内容 |
|---|---|
| `Trade.ensure(league, ilvl)` | 出品を作るレベルを決め、ほかの冒険者の出品と依頼を補充する（取引所を開くときと `complete_map`） |
| `Trade.tags(it)` / `Trade.tag_names(ts)` | 装備のタグ（`TAGS` のキー）と、その表示名 |
| `Trade.value(league, it)` | 装備の相場 V（c）。`base_value(it)` は段階と流行を掛ける前の値 |
| `Trade.unique_tier(name)` | ユニークの人気 `{tier, base}` |
| `Trade.events(league)` / `Trade.board(league)` | 装備の流行 `{tag, mult, start, days}` と、掲示板用（`Market.board` にも含まれる） |
| `Trade.sell_rate(league, it, ask)` / `Trade.list_estimate(league, it, ask)` | 出品の売れる確率と見積もり `{value, rate, ticks, fee, dealer}` |
| `Trade.list_item(league, bag, i, ask, wallet)` | 出品する（手数料は灰燼で先払い） |
| `Trade.dealer_sell(league, bag, i, wallet)` | 業者に即売りする（`dealer_price` 混沌） |
| `Trade.unlist(league, id, bag, bag_size)` | 出品を取り下げる（所持品が一杯なら受け取り箱へ） |
| `Trade.take_held(league, i, bag, bag_size)` | 受け取り箱から所持品へ |
| `Trade.buy_offer(league, id, bag, bag_size, wallet)` | ほかの冒険者の出品を買う |
| `Trade.request_text(r)` / `Trade.match_index(league, r, bag)` | 依頼の説明文と、納品される所持品の番号（なければ -1） |
| `Trade.deliver(league, id, bag, wallet)` | 依頼に納品して報酬を受け取る |
| `Trade.listings(league)` | 出品中の装備（`ticks_left` つき） |
| `Trade.dissolve_items(m)` | 捨てる相場に残っている装備（出品中と受け取り箱） |

## 12. 出品検索（フェーズ4、#65）

取引所の「出品検索」ページ（`scripts/exchange.gd` の `Exchange`、画面は `ExchangeUI`）。最初は何も並ばず、検索した条件に合う出品をその場で最大 `RESULTS`（12）件作る。

- 種類：装備・石板・燈晶・環晶・燼殻・ジェム・カレンシー（`CATEGORIES`）。条件は部位・レア度・ベース名・ユニーク名・オプション（最大 3 つ、それぞれ最低値。装備は刻紋 `sp:<k>` も）・アイテムレベル・価格の範囲。
- 指定したベース・ユニーク・オプションは必ず付け、各オプションは最低値以上（`min_t` で範囲の何割から振るかを求め、その上で振る）。残りはふだんどおりランダム。
- シード：条件・リーグ・市場のティック・入れ替え回数。同じ条件なら同じ出品（マップ踏破か「出品を入れ替える」で変わる）。買った出品は `Exchange.sold` に残り、同じ検索でも売約済みのまま。
- ありえない条件（その部位に付かないオプション、同時に付く部位がない組み合わせ、届かない最低値、マジックに 3 つ、ノーマルにオプション、ユニークの部位・ベース違いなど）は `check` が理由を返し、画面に表示する。

### 価格（混沌、ほかに `Market.fee` の灰燼）

```
価格 = max(価値 × 3 × 出品者(0.9〜1.25) × 条件の倍率, 売り直しで得られる額 × 2)
条件の倍率 = (ベース 1.15 | 部位 1.05) × (レア度 1.1) × (ユニーク名 1.25) × (1 + 0.02 × 隠れ家より上の iLv)
           × Π_i (1 + 0.45 × 希少さ_i × (1 + 1.5 × q_i)) × (1 + 0.25 × i)    （i = 0, 1, 2 は指定したオプションの順）
希少さ = 平均の出やすさ / そのオプションの出やすさ（Data.AFFIXES の w、0.5〜4）。刻紋は 5
q = 最低値が範囲のどこか（0 = 最小、1 = 最大）
```

価値は装備なら `max(Trade.base_value, 売却額 / 250)`（ユニークは希少度ごとの人気が入る）、石板・ジュエルは砕いた灰燼 / 250（行数ぶん上乗せ）、燼殻は `Charms.value` / 250、ジェムは商人の値段 / 250、カレンシーは相場 × 個数。売り直しの額（業者は流行の段階込みの最大 1.4 倍まで見込む・商人・砕く・相場の売り）の 2 倍を下回らないので、買ってすぐ売っても必ず損になる。
