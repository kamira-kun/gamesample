# 経済システム設計（フェーズ1：通貨取引所）

ソロでもトレードリーグらしい経済を味わえるように、仮想の市場参加者をシミュレートする。
フェーズ1では **クラフト通貨の取引所** だけを作り、装備の取引はフェーズ2以降に回す。

## 決定事項

| 項目 | 決定 |
|---|---|
| 基軸通貨 | 混沌の残光（相場はすべて「c」建て。混沌自身は常に 1c） |
| 灰燼の欠片 | 取引所では売買できない NPC 専用のお金。取引手数料の支払いに使う |
| 時間の進め方 | プレイ量で進む。現実の時計は使わない |
| 固定価格の通貨販売 | 割高にして残す（相場の上限＝安全弁） |
| 相場の流れ | シーズンIDをシードにして、流行・出来事を固定。細かい値動きはランダム |

## 1. 時間

- **市場ティック**：マップを1つ完了してハイドアウトに戻るたびに 1 ティック進む。
- **市場日**：10 ティック = 1 市場日。シーズンの段階や価格推移グラフはこの単位で数える。
- 現実の日付はシーズンの開催期間の判定だけに使う（今の仕組みのまま）。

## 2. 価格のモデル

通貨ごとに **目標価格 P\*** と **現在価格 P** を持つ。

```
P* = 基本価値 × シーズン段階補正(市場日) × 出来事補正(市場日)
```

### 基本価値
`CURRENCIES` の既存の `value` を混沌の value（25）で割った値。

| 通貨 | value | 基本価値 |
|---|---|---|
| 変容の結晶 | 5 | 0.20c |
| 浄化の雫 | 8 | 0.32c |
| 羅針の欠片 | 12 | 0.48c |
| 鍛錬の砥石 | 15 | 0.60c |
| 昇華の焔 | 20 | 0.80c |
| 混沌の残光 | 25 | 1c（固定） |
| 神秘の核 | 80 | 3.2c |

### シーズン段階補正
通貨ごとに `early`（シーズン開始時）と `late`（成熟後）の倍率を持ち、市場日 0〜30 の間で滑らかに移る。

```
段階補正 = lerp(early, late, smoothstep(0, 30, 市場日))
```

- 安い通貨（変容・浄化）：early 1.5 → late 0.7（序盤は需要があり、だんだん余る）
- 中くらいの通貨（砥石・昇華・羅針）：early 1.2 → late 0.9
- 高い通貨（神秘）：early 0.8 → late 1.6（終盤ほど高騰）
- スタンダードリーグは常に `late`（成熟した市場）。

### 毎ティックの値動き

```
P ← P + 0.15 × (P* − P) + 0.03 × P × N(0, 1)
P は 0.25 × 基本価値 〜 4 × 基本価値 の範囲に収める
```

目標価格に引き戻されつつ、少し揺れる。

### プレイヤーの売買による影響
通貨ごとに **市場の厚み D**（変容 300、浄化・羅針・砥石 150、昇華 100、神秘 30）を持つ。

```
q 個売る： P ×= (1 − 0.5 × q / D)
q 個買う： P ×= (1 + 0.5 × q / D)
```

動いた価格は、上の引き戻しで数ティックかけて元に戻る。
大量に売りさばくと値崩れするので、少しずつ売るか、指値で待つほうが得になる。

## 3. 売買の種類

### 成行（すぐに成立）
- 買値 = P × (1 + スプレッド/2)、売値 = P × (1 − スプレッド/2)
- スプレッド：変容・浄化 6%、その他 8%、神秘 12%
- 1回の注文の途中でも価格が動く（1個ずつ影響を積み上げて計算する）

### 指値（出品して待つ）
- 値段と数量を決めて出品する。スプレッドはかからない。
- 売り注文の値段が現在価格以下なら、その場で成行として成立する。
- それより高い場合は、毎ティック一部だけ成立する。

```
1ティックで成立する割合 = 0.3 × exp(−8 × (指値 / P − 1))
```

| 指値 | 1ティックで成立する割合 |
|---|---|
| 現在価格 +5% | 約 20% |
| +20% | 約 6% |
| +50% | 約 0.5% |

- 買い注文も同じ式を左右反対にして使う。
- 同時に出せる注文は 8 件まで。50 ティック経っても残っている分はスタッシュに戻す。
- 成立した結果は、ハイドアウトに戻ったときにまとめて通知する（「マップから戻ったら売れていた」体験）。

### 手数料（灰燼の欠片の使い道）
```
手数料（灰燼） = max(5, ceil(取引額(c) × 8))
```
成行・指値どちらも、成立した時点で支払う。払えない場合は注文できない。

## 4. 商人の固定価格販売（相場の上限）

```
商人の販売価格（灰燼） = round(相場(c) × 250 × discount)
```
- 混沌の残光は 250 灰燼（今は 100）。
- 相場が上がれば商人の値段も上がるが、灰燼でいつでも買える＝極端な高騰は起きない。
- 商人は通貨を買い取らない。灰燼→通貨の一方通行なので、行ったり来たりで稼ぐことはできない。

## 5. シーズンの出来事（シード固定）

シーズンIDのハッシュをシードにして、シーズンごとに 3〜5 件の出来事を作る。

```
{ 通貨, 倍率 (0.6〜1.8), 開始する市場日, 続く日数 (3〜8) }
```
例：「鍛錬の砥石ブーム：市場日 5〜12 の間、需要 ×1.4」

- 同じシーズンなら誰が遊んでも同じ流れになる（テストもしやすい）。
- ハイドアウトの **相場掲示板** で、始まる 1 日前に予告し、開催中は表示し続ける。
- フェーズ2で、ユニークのタグ（召喚・火など）を対象にした流行に広げる。

## 6. 保存

リーグ共有スタッシュと同じく **リーグごと** に保存する。

```
market = {
  tick: int,
  prices: { 通貨キー: P },
  orders: [ { id, side: "buy"|"sell", k, qty, filled, limit, placed_tick } ],
  history: { 通貨キー: [直近 60 市場日の終値] },
  pending: [ 次にハイドアウトへ戻ったときに出す通知 ],
}
```

- シーズン終了で移行するとき、そのリーグの相場は捨てる。残っていた注文は、預けていた通貨をスタンダードのスタッシュに返す。
- 新しいシーズンは、すべての通貨を `early` の目標価格から始める。

## 7. 画面

ハイドアウトに **取引所** の窓口を置く（商人の画面のタブにしてもよい）。

- **相場一覧**：通貨ごとに現在価格、前日比、直近 14 市場日のミニグラフ
- **売買**：成行／指値の切り替え、数量、指値、成立見込み（「約 N ティックで売れそう」）、手数料
- **注文一覧**：出している注文の進み具合と取り消しボタン
- **相場掲示板**：開催中・予告中の出来事

## 8. 稼ぎすぎの防止の確認

- 成行で買ってすぐ売る：スプレッド＋影響＋手数料で 10% 以上損をする。
- 商人で買って取引所で売る：250 灰燼で買った 1c を売っても 1c 弱にしかならず、灰燼を通貨に換えるだけで得はない。
- 同じ物を大量に売る：値崩れして、まとめて売るほど 1 個あたりが安くなる。

## 9. テスト（スモークテストに追加）

- プレイヤーが何もしないで 300 ティック進めても、全通貨が 0.25〜4 × 基本価値の範囲に収まる。
- 同じシーズンIDなら、出来事の一覧が毎回同じになる。
- 成行で買ってすぐ売ると、通貨が減る。
- 指値の売り注文が、何ティックか後に成立して、混沌と通知が増える。
- シーズン移行で、残っていた注文の通貨がスタンダードのスタッシュに戻る。

## フェーズ1でやらないこと

- ユニーク・レア装備の取引（フェーズ2・3）
- NPC の買取依頼（フェーズ3）
- SSF リーグ（取引なし）

## API（`godot/scripts/market.gd` の `Market`）

相場の状態は `Profiles.data.market[リーグ]` にあり、リーグ共有スタッシュと一緒に保存される。
`league` は `main.league()`、`wallet` は `player.cur`（通貨キー → 個数）を渡す。
`k` は取引所で扱う通貨キー（`Market.keys()`。灰燼と混沌は含まない）、`side` は `"buy"` か `"sell"`。
失敗を返す関数は、成功なら `""`、失敗ならプレイヤーに見せる理由の文字列を返す。

### 参照
| 関数 | 返り値 |
|---|---|
| `Market.keys()` | 取引できる通貨キーの配列（`CURRENCIES` の順） |
| `Market.price(league, k)` | 現在価格（c）。`"chaos"` は常に 1.0 |
| `Market.day_change(league, k)` | 前の市場日の終値からの変化率（0.05 = +5%）。終値がまだなければ 0 |
| `Market.history(league, k, days := 14)` | 直近 `days` 市場日の終値（古い順） |
| `Market.target(league, k, day)` | 市場日 `day` の目標価格 P* |
| `Market.day(Market.state(league))` | 今の市場日（小数。tick / 10） |
| `Market.events(league)` | シーズンの出来事 `{k, mult, start, days}` の配列（スタンダードは空） |
| `Market.board(league)` | 相場掲示板用：開催中・翌日開始の出来事。各要素に `state`（`"active"`/`"soon"`）と `text` を追加 |
| `Market.event_text(e)` | 出来事の説明文 |
| `Market.orders(league)` | 出している注文 `{id, side, k, qty, filled, limit, placed_tick, left, ticks_left, ...}` |
| `Market.fee(value_c)` | 取引額 `value_c`（c）の手数料（灰燼） |

### 見積もり
| 関数 | 返り値 |
|---|---|
| `Market.quote(league, k, side, qty)` | 成行の見積もり `{total, avg, chaos, fee, end_price}`。`chaos` は実際に払う／受け取る混沌（買いは切り上げ、売りは切り捨て） |
| `Market.fill_rate(league, k, side, limit)` | 指値が 1 ティックで成立する割合（1.0 ならその場で成行として成立） |
| `Market.limit_estimate(league, k, side, limit, qty)` | `{rate, ticks, fee, cost, instant}`。`ticks` は全部成立するまでの目安（-1 は期限の 50 ティック内には難しい）、`cost` は預ける混沌（買い）か通貨の個数（売り） |

### 操作
| 関数 | 内容 |
|---|---|
| `Market.market_trade(league, k, side, qty, wallet)` | 成行で売買する。手数料も `wallet` の灰燼から払う |
| `Market.place_limit(league, k, side, limit, qty, wallet)` | 指値を出す。売りは通貨、買いは混沌と、全量分の手数料を預ける（成立分の手数料を差し引いて、残りは閉じるときに返す）。現在価格を越える指値は成行として成立 |
| `Market.cancel(league, id, wallet)` | 注文を取り消し、預けた分を `wallet` に返す。見つからなければ false |
| `Market.take_notes(league)` | ハイドアウト帰還時に出す通知（文字列の配列）を取り出して消す |
| `Market.tick(league, wallet)` | 1 ティック進める（`main.complete_map` が呼ぶ。UI からは呼ばない） |

### 補足
- 指値の成立・期限切れの返却は、ティックの時点で `wallet`（そのとき帰還したキャラクターの所持通貨）に入る。
- シーズン終了時（`Profiles.migrate`）は相場を捨て、注文が預かっていた通貨と未使用の手数料を
  `Profiles.stash_cur("standard")` に入れる。スタンダードのキャラクターを読み込むと
  `Profiles.take_stash_cur` で所持通貨に移り、メッセージが出る。
