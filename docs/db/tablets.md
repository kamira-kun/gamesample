# ルーンタブレットと特殊修飾子

ルーンタブレットはボスが必ず1つ落とします（半分は能力を1行刻んだ状態、残りは無地）。6×6のタブレット盤に回して置き、盤に置いたルーンタブレットの能力だけが効きます。刻紋の熾石は刻紋の封碑（マップの約55%に1つ。封印を解いて番人をすべて倒す）からだけ得られます。

## ルーンタブレットのクラフト

タブレット盤で選んだルーンタブレットに使います。

| カレンシー | 効果 |
|---|---|
| ◈ 鍛錬の砥石 | 能力を1行刻む（刻める行数まで） |
| ✺ 混沌の残光 | 刻んだ能力をすべて刻み直す（行数はそのまま） |
| ✷ 神秘の核 | 能力の数値だけを振り直す |
| （砕く） | 盤に置いていないルーンタブレットを灰燼の欠片に変える |
