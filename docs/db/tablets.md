# 石板と特殊修飾子

石板はボスが必ず1つ落とします（半分は能力を1行刻んだ状態、残りは無地）。6×6の石板盤に回して置き、盤に置いた石板の能力だけが効きます。刻紋の熾石は刻紋の封碑（マップの約55%に1つ。封印を解いて番人をすべて倒す）からだけ得られます。

## 石板のクラフト

石板盤で選んだ石板に使います。

| カレンシー | 効果 |
|---|---|
| ◈ 鍛錬の砥石 | 能力を1行刻む（刻める行数まで） |
| ✺ 混沌の残光 | 刻んだ能力をすべて刻み直す（行数はそのまま） |
| ✷ 神秘の核 | 能力の数値だけを振り直す |
| （砕く） | 盤に置いていない石板を灰燼の欠片に変える |

## 特殊修飾子

✠ 刻紋の熾石でレアアイテムに1つだけ刻めます。オプションの数には数えず、混沌の残光でも消えません（浄化の雫で消えます）。もう一度使うと別の特殊修飾子に刻み直します。
