# コンパス

コンパスは燼火で針を灯した真鍮の羅針盤です。遠征図で出撃前に 4 つまで（同じ系統は1つまで）はめると、そのマップ1回にだけ効果が加わり、マップに入ると燃え尽きます。マップの敵が落とし（ボス 60%・エリート 5%・通常 0.4%）、所持品とスタッシュで重ねて持てます。エリアレベルが高いほど上の階位が出やすくなります。

> このファイルはゲームのデータから自動生成しています（`godot --headless --path godot -s tools/gen_docs.gd`）。手で編集しないでください。
