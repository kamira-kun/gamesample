# 遠征地図と Tier

遠征地図は50種のマップ（5属性×10）のどれかを、地図に書かれた Tier で開きます。Tier に上限はありません（数値が壊れないよう T9999 で頭打ち）。Tier N のマップの敵は Tier N±1 の地図を、ボスは N〜N+2 の地図を落とすので、より深い Tier へ進めます。地図装置は T1 の地図を ◆ 100 で売り、持っている地図を価値の 40% で買い取ります。取引所の「遠征地図」でも Tier を指定して買えます（価格は価値が基準）。

## Tier ごとの強さと報酬
