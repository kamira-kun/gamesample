# ベースキャラとアセンダンシー

キャラクター作成時にベースキャラを3つから選び、そのベースキャラの3つのアセンダンシー（血統）から1つを選びます。アセンダンシーポイントは2レベルごとに1点（Lv2 で最初の1点）。マイナーノードに振った合計が 2・5・8 に達するとコアの段が順に開放され、各段で2つのうち1つを選びます。
