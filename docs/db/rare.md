# レア装備とオプション

ユニーク以外の装備は、ベースアイテムにランダムなオプションが付いたものです。レアは3〜4個のオプションを持ち、名前はランダムな2語から作られます。

> このファイルはゲームのデータから自動生成しています（`godot --headless --path godot -s tools/gen_docs.gd`）。手で編集しないでください。

## レア度

ドロップ率は補正なしの基本値。マップのレア度補正・エリート・ボスで上位のレア度が出やすくなります。

| レア度 | オプション数 | 基本ドロップ率 | 名前 |
|---|---|---|---|
| ノーマル | なし | 60.2% | ベースの名前 |
| マジック | 1〜2 個 | 29.1% | 最初のオプションの語＋ベース名（例：猛き片手剣） |
| レア | 3〜4 個 | 9.0% | ランダムな2語（例：災厄の牙） |
| レジェンド | 3〜4 個 | 1.6% | ユニークの名前 |
