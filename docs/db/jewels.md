# ジュエルとリングジュエル

ジュエルは敵が落とします（ボス60%、エリート12%、通常0.6%。そのうちリングジュエルはボス40%・ほか15%）。1キャラクターにつき40個まで（ユニークは数えません）持て、パッシブツリーの画面（T）で台座に出し入れし、クラフトします。

> このファイルはゲームのデータから自動生成しています（`godot --headless --path godot -s tools/gen_docs.gd`）。手で編集しないでください。

## ジュエルのベース

ジュエルはジュエルの台座に入れ、その台座ノードを取得している間だけ効きます。レア度はノーマル・マジック・レア（オプション数は装備と同じ）。

| ベース | 固定の能力 |
|---|---|
| 灰のジュエル | 最大ライフ +8 |
| 燼のジュエル | 最大マナ +8 |
| 影のジュエル | クリティカル率 +1% |

## リングジュエルの大きさ

リングジュエルは最外周のリングジュエルの大台座に入れると、その先に小ノード・注目ノード・（大リングジュエルなら）ジュエルの小台座の環が伸びます。外すと環のノードに振ったポイントは戻ります。

| 大きさ | 小ノード | ジュエルの小台座 | 注目ノード |
|---|---|---|---|
| 小リングジュエル | 4 | なし | マジック 1・レア 1〜1 |
| リングジュエル | 6 | なし | マジック 1・レア 2〜2 |
| 大リングジュエル | 8 | 1 | マジック 1・レア 2〜3 |

## クラフト

台座に入れたままでは使えません。

| カレンシー | 効果 |
|---|---|
| 変容の結晶 | ノーマル→マジック（ジュエルはオプション1〜2、リングジュエルは注目ノード1） |
| 昇華の焔 | マジック→レア（ジュエルはオプション3〜4まで、リングジュエルは注目ノードを上限まで） |
| 混沌の残光 | オプションを作り直す（リングジュエルは主題と注目ノード） |
| 鍛錬の砥石 | オプション（リングジュエルは注目ノード）を1つ追加 |
| 浄化の雫 | ノーマルに戻す |
| 神秘の核 | 数値（リングジュエルは環の強さ）を振り直す |
