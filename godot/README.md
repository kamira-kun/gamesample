# Emberfall (Godot 4)

ブラウザ版プロトタイプを Godot 4 に移植したプロジェクトです（ブラウザ版はリポジトリから外し、手元の `OLD/` にだけ残しています）。

## 開き方
1. Godot 4.7 を起動し、「インポート」でこのフォルダの `project.godot` を選ぶ
2. F5（プロジェクトを実行）で遊べます

## 操作
| キー | 動作 |
|---|---|
| WASD | 移動（画面の上下左右） |
| 左クリック / 右クリック / Q / E / R / Space | スキルバーのスキル（初期：斬撃・ファイアボール・フロストノヴァ・チェインライトニング・メテオ・シャドウダッシュ） |
| F | 回復薬 |
| I / Tab | インベントリ |
| K | スキルとサポートジェム（スキルバーのスロットをクリックしても開く） |
| T | タレント |
| U | アセンダンシー |
| C | ステータス |
| L | ルートフィルタ |
| P | 遠征パッシブ（遠征図の画面からも開ける） |
| B / 左クリック | 隠れ家で商人・遠征図の祭壇・スタッシュを開く（近くで B） |
| Esc | 開いている画面を閉じる。何も開いていなければ一時停止（マップの放棄はここから） |

起動するとキャラクター選択画面が開きます。キャラクターは「シーズン」か「スタンダード」のどちらかで作成し、一時停止メニューからいつでも選択画面に戻れます。ゲームは隠れ家から始まります。遠征図の祭壇でマップを選んで出撃し、ボスを倒してポータルに入ると踏破となり、隣のマップが開放されて隠れ家に戻ります。商人は隠れ家にだけいて、踏破のたびに品揃えが入れ替わります。

スキルは全65種で、Lv1〜18 にかけて習得していきます（K の画面ではタグで絞り込め、未習得のものには習得レベルが出ます）。習得したスキルは6つのスロットに好きに付け替えられます。スキルは「前方を薙ぐ」「投射物」「カーソル位置の範囲」「持続範囲」「強化」「呪い」「召喚」「移動」などの効果ブロックを組み合わせたデータで定義されています。移動スキル（シャドウダッシュ・瞬歩・跳躍斬）以外にはクールダウンがなく、連射の速さは攻撃速度・詠唱速度とマナで決まります。

サポートジェム（全60種。威力増幅・多重投射・トーテム化・軍勢・罠化・残響など）は敵のドロップか商人で手に入り、スロットにリンクするとそのスキルの挙動が変わります。ジェムはスキルのタグに合うものだけが効きます。骸骨とトーテムは敵からも狙われます。
- **オーラ**：炉辺の守り火（Lv3）・熾火の鼓動（Lv5）・霜紗の帳（Lv8）・風詠みの讃歌（Lv11）・紅血の誓約（Lv14）の5種。スロットのキーを押すたびに発動／解除が切り替わり、発動中は自分と周囲9m以内の味方（ミニオン・トーテム）に効果が続きます。代わりに最大マナ（紅血の誓約は最大ライフ）の一定割合か固定値を「リザーブ」し、その分だけ使える上限が減ります。オーブの上部にリザーブ分がふたをされたように表示され、数字は残りの上限を示します。複数を重ねられますが、リザーブの合計が最大値を超える（ライフは1以上残らない）ときは発動できません。サポートジェムの「効率化」でリザーブが減り、「鼓舞」で効果が上がります（リザーブは増える）。装備やリンクの変更で足りなくなると、最後に発動したオーラから解除されます。発動状態はセーブされます。
- **エネルギー**：ジェムはそれぞれエネルギーを1〜3消費し、リンクの合計はエネルギー上限（2＋キャラクターレベル＋装備の「エネルギー上限」）まで。1スロットにつきリンクは最大6個です。装備を外して上限が下がると、スキルバーの後ろのスロットのリンクから無効になります。

- **タレント**：レベルが上がるたびに1ポイント。基本能力か、スキルごとのダメージに振れます。
- **アセンダンシー**：4系統の血統（焔王＝火炎スペル、剣聖＝攻撃と耐久、霜雷の巫女＝冷気・雷とクリティカル、冥導師＝ミニオンとトーテム）から1つを選びます（最初の選択は無料）。2レベルごとに1ポイント（Lv2 で最初の1点）得て、血統ごとの4つのマイナーノード（各最大3ランク）に振ります。振った合計が 2・5・8 に達するとコアタレントの段が順に開放され、各段で2つのうち1つを選びます（コアの選択はいつでも無料で入れ替え可能）。血統の選び直しには振ったポイント×25 の灰燼の欠片がかかります。
- **ルートフィルタ**：レア度ごとに「拾う／拾って売却／非表示（落ちた瞬間に売却）」を選べ、部位ごとに拾わない設定もできます（レジェンドは除く）。
- **灯り狐**：いつもそばにいるペット。近くに落ちたカレンシーやアイテムを拾ってきます。ボスを倒してポータルに入ると、周りに残ったアイテムもまとめて回収します。
- **ボス**：マップの地形でボスが変わります（地下墓所＝深淵の番人、溶岩の洞窟＝灼熱の巨像、凍てつく聖堂＝凍嵐の魔女）。巨像は炎の跡を残す突進と隕石、魔女は瞬間移動と移動速度を下げる冷気を使い、どちらもライフ半分で激昂します。
- **シーズン**：開催期間は `scripts/data.gd` の `SEASONS`（UTC の日付）で決まります。シーズン中だけそのシーズンのキャラクターを作成できます。シーズンが終わると、次の起動時にそのシーズンのキャラクターはスタンダードへ移行し（選択画面に「元シーズン」と表示）、シーズンのスタッシュはスタンダードのスタッシュに「シーズン名 1, 2…」のタブとして追加されます。開発中は `-- --date=2027-02-01` のように日付を偽装して終了を試せます。
- **スタッシュ**：隠れ家の宝箱。リーグ（各シーズン／スタンダード）ごとに共有で、同じリーグのキャラクター同士でアイテムを受け渡せます。1タブ48マス×4タブ。
- **セーブ**：全キャラクターとスタッシュを `user://emberfall_profiles.json` に保存します。以前の `emberfall_save.json` は初回起動時にスタンダードのキャラクター「放浪者」として取り込まれ、元のファイルはバックアップとしてそのまま残ります。
- **ユニーク（レジェンド）**：1000種。部位と武器種ごとに散らばり、固定の能力値（中には代償となるマイナス値も）と、スキルの挙動やビルドの軸を変える効果（アセンダンシーの核タレントや「クリティカルを捨ててダメージ +45%」などの固有効果）を持ちます。
- **遠征パッシブ**：初踏破と残り火の深淵の踏破ごとに1ポイント。財宝・征服・探索の3系統で、上から順に開放されます。ポイントは灰燼の欠片で振り直せます。
- **ステータス画面のキャラクター画像**：C の画面の左に、いま装備している武器を持ったヒロインが表示されます。「画像を読み込む」で好きな画像（PNG・JPG・WebP）に差し替えられ、「3D表示に戻す」で元に戻ります。読み込んだ画像はユーザーデータ（Windows では `%APPDATA%\Godot\app_userdata\Emberfall\portrait.png`）にコピーされるので、リポジトリには入りません。

## 構成
- `scripts/main.gd` — ゲームループ、ダンジョンの3D化、スキル・敵AI・戦闘、カメラ
- `scripts/dungeon.gd` — 部屋と通路のダンジョン生成、経路探索（ゲームの計算は平面グリッド上）
- `scripts/player.gd` / `enemy.gd` / `actor.gd` — キャラクターと仮モデル
- `scripts/heroine.gd` — 操作キャラの見た目（騎士の体にローグの顔、ピンクの髪・アホ毛・丸メガネ、紺と銀の鎧）
- `scripts/hud.gd` — HUD（オーブ、スキルバー、体力バー、ダメージ数字、死亡画面）
- `scripts/items.gd` / `inventory_ui.gd` / `item_slot.gd` — アイテム生成・クラフト・インベントリ画面
- `scripts/item_icon.gd` — 装備のベースごとのアイコン（ベクター描画）
- `scripts/skill_icon.gd` — スキルとサポートジェムのアイコン（ベクター描画。属性色の枠＋スキルごとの発光モチーフ、ジェムは対象でカットが変わる）
- `scripts/atlas.gd` / `atlas_ui.gd` — 遠征図の進行状況（踏破・開放・マップ効果）と画面
- `scripts/shop_ui.gd` — 隠れ家の商人
- `scripts/profiles.gd` — キャラクター一覧・リーグ別スタッシュのセーブと、シーズン終了時の移行
- `scripts/char_ui.gd` / `stash_ui.gd` — キャラクター選択（作成・削除）とスタッシュの画面
- `scripts/skill_ui.gd` — スキルとサポートジェムの画面（スロットへの付け替え、ジェムのリンクとエネルギー）
- `scripts/base_panel.gd` — 中央に開く画面の共通枠
- `scripts/portrait.gd` — ステータス画面のキャラクター画像（読み込んだ画像か、装備を反映した3Dのヒロイン）
- `scripts/talent_ui.gd` / `status_ui.gd` / `filter_ui.gd` / `passive_ui.gd` / `pause_ui.gd` — タレント・ステータス・ルートフィルタ・遠征パッシブ・一時停止の画面
- `scripts/asc_ui.gd` — アセンダンシーの画面（血統の選択、マイナーノード、コアタレント）
- `scripts/ally.gd` — 骸骨召喚のミニオンとトーテム
- `scripts/pet.gd` — 灯り狐
- `scripts/fx.gd` — 仮メッシュ・マテリアル・エフェクトの生成
- `scripts/uniques.gd` — ユニーク1000種のデータ（`tools/gen_uniques.py` で書き出し、`godot --headless --path . -s tools/run_check.gd` で検査）
- `scripts/data.gd` — スキル・サポートジェム・敵・タレント・アセンダンシー・テーマ・遠征図のデータ（オートロード `Data`）
- `scripts/assets.gd` / `level_builder.gd` — KayKit 素材の読み込みと、ダンジョンへの床・壁・たいまつ・小物の配置

## 開発用
自動テスト（商人（通貨は相場×250 灰燼）・取引所の画面（成行・指値・取り消し・帰還時の通知）・遠征図・全スキル発動・罠とトーテムとサポートジェム・全サポートジェムの適用先・リンクのエネルギー予算（最大6リンク、予算超過の拒否、予算が減ったときの無効化）・タレント・アセンダンシー（系譜の選択、基礎ノード、コアタレント3段階、ポイントと選び直し）・ルートフィルタ・ペット・遠征パッシブ・巨像と魔女の技・ボス撃破・踏破・死亡と再挑戦・アイテムとクラフト・オーラ（発動と解除、リザーブと上限、重ね掛けと発動拒否、ジェムによるリザーブの増減、範囲内の味方、HUDのオーブ、セーブの往復））。セーブファイルには書き込みません:
```
Godot_v4.7.2-stable_win64.exe --headless --path . -- --smoke
```

画面を1つだけ開いて確認する場合（セーブは読み書きしません）。`merchant` `device` `stash` `exchange`（市場日 6、注文1件と指値の売りを用意） `skills` `talents` `ascend`（育成途中の霜雷の巫女） `ascend_pick`（血統の選択） `status` `filter` `passives` が使えます。`colossus` `witch` では最初のマップでそのボスがすぐ横に出ます。`aura0`（オーラをスロットに並べただけ） `aura`（3秒後に4つ発動し5つ目は拒否） `aura_off`（さらに1つ解除）ではオーラとリザーブの表示を確かめられます。`--shot=<パス>` を付けると4.5秒後の画面をPNGに保存して終了します:
```
Godot_v4.7.2-stable_win64.exe --path . -- --view=merchant
Godot_v4.7.2-stable_win64.exe --path . -- --view=colossus
```
