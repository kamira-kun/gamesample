# Emberfall (Godot 4)

ブラウザ版プロトタイプを Godot 4 に移植したプロジェクトです（ブラウザ版はリポジトリから外し、手元の `OLD/` にだけ残しています）。

## 開き方
1. Godot 4.7 を起動し、「インポート」でこのフォルダの `project.godot` を選ぶ
2. F5（プロジェクトを実行）で遊べます

## 操作
| キー | 動作 |
|---|---|
| WASD | 移動（画面の上下左右） |
| 左クリック / 右クリック / Q / E / R / Space | スキルバーのスキル（初期：斬撃・ファイアボール・フロストノヴァ・チェインライトニング・メテオ・シャドウダッシュ） |
| F | 回復薬 |
| I / Tab | インベントリ |
| K | スキルとサポートジェム（スキルバーのスロットをクリックしても開く） |
| T | パッシブツリー |
| U | アセンダンシー |
| C | ステータス |
| L | ルートフィルタ |
| P | 遠征パッシブ（遠征図の画面からも開ける） |
| G | タブレット盤 |
| M | マップ（オーバーレイ）の表示／非表示 |
| B / 左クリック | 隠れ家で商人・遠征図の祭壇・スタッシュを開く、燼藁のカカシの計測をリセット（近くで B） |
| O | キー設定 |
| Esc | 開いている画面を閉じる。何も開いていなければ一時停止（マップの放棄はここから） |
| Alt（押している間） | アイテム・ジュエル・リングジュエル・ルーンタブレットのツールチップに、各行の数値が取りうる範囲（下限–上限）とオプション名を出す |

上は既定のキーです。**キー設定**（O、または一時停止メニューの「キー設定」）で、Esc 以外のすべての操作を好きなキーやマウスボタン（左・右・中・マウス4/5）に割り当て直せます。割り当て欄をクリックしてから押したキーが入り、右クリックで解除、各操作に2つまで割り当てられます。ほかの操作で使っているキーを選ぶと、その操作と入れ替わります（どう入れ替わったかは画面の下に表示）。「既定に戻す」ですべて元に戻ります。Esc と Alt は固定で、ほかの操作には割り当てられません（以前の設定ファイルに Alt の割り当てがあれば読み込み時に外れます）。割り当てはキャラクターではなくユーザー設定として `user://emberfall_settings.cfg`（Windows では `%APPDATA%\Godotpp_userdata\Emberfall\`）に保存され、起動時に読み込まれます。スキルバーやヒント・メッセージに出るキーの表記も割り当てに合わせて変わります。

起動するとキャラクター選択画面が開きます。キャラクターは「シーズン」か「スタンダード」のどちらかで作成し、一時停止メニューからいつでも選択画面に戻れます。ゲームは隠れ家から始まります。遠征図の祭壇でマップと地図（入場アイテム）の Tier を選んで出撃し、ボスを倒してポータルに入ると踏破となって隠れ家に戻ります（下の「遠征図とマップ」）。商人は隠れ家にだけいて、踏破のたびに品揃えが入れ替わります（手数料を払えばその場で入れ替えも可能）。品揃えは**装備・ルーンタブレット・ジュエル・リングジュエル・コンパス・ジェム・カレンシー**のタブに分かれ、装備は全7部位×6点＝42点（ノーマルからユニークまで、隠れ家のレベル〜＋2）を部位とレアリティで絞り込めます。ほかにルーンタブレット8枚、ジュエル5個とリングジュエル5個、コンパス12個（階位は高めに混ざる）が並びます。値段は `Data.SHOP_PRICE`（2.5）ひとつで全体が決まり、装備は売却額×5×2.5にオプション1行ごと＋12%、ルーンタブレットとジュエルは砕いたときの欠片×4×2.5に行数ぶん上乗せ、コンパスは基準価値×2.5です。どれも割り引かれても売却・砕いたときの額の2倍を下回らないので、買ってすぐ売っても得はしません。

スキルは全65種。最初に使えるのはベースキャラの初期スキルバーの6つだけで、ほかは**スキルジェム**として敵のドロップか商人で手に入れます。スキルとサポートジェムにはそれぞれ**必要レベル**（スキル Lv1〜18、サポート Lv1〜16）があり、持っていてもそのレベルになるまではスロットに付けたりリンクしたりできません（K の画面ではタグで絞り込め、未入手・レベル不足のものにはその旨と必要レベルが出ます）。ジェムのドロップはそのエリアのレベル＋2 までのものが中心で、商人には「キャラクターのレベル＋3」までの未入手のジェムが並びます（値段は必要レベルで上がる）。持っているジェムをまた拾うと灰燼の欠片になります。スキルジェム導入前のキャラクターは、そのレベルで習得済みだったスキルをすべて持った状態で読み込まれます。手に入れたスキルは6つのスロットに好きに付け替えられます。スキルは「前方を薙ぐ」「投射物」「カーソル位置の範囲」「持続範囲」「強化」「呪い」「召喚」「移動」などの効果ブロックを組み合わせたデータで定義されています。移動スキル（シャドウダッシュ・瞬歩・跳躍斬）以外にはクールダウンがなく、連射の速さは攻撃速度・詠唱速度とマナで決まります。

サポートジェム（全60種。威力増幅・多重投射・トーテム化・軍勢・罠化・残響など）も敵のドロップか商人で手に入り、スロットにリンクするとそのスキルの挙動が変わります。ジェムはスキルのタグに合うものだけが効きます。骸骨とトーテムは敵からも狙われます。
- **覚醒ジェム**：サポートジェム60種それぞれの強化版（「覚醒・威力増幅」など、アイコンに金の輪）。利点が1.5倍になり（欠点とエネルギーはそのまま）、ダメージが利点でないジェムはさらにダメージ +10%。必要レベルは元のジェムの＋8（最低 Lv12）で、それまではリンクできません（K の画面とツールチップに必要レベルが赤く出ます）。同じスキルに元のジェムと一緒にはリンクできません。手に入るのは **Lv8 以上のエリアのエリート（1.5%）とボス（12%）のドロップ**と**取引所の出品検索**（ジェムの検索で12件中2件が覚醒ジェムになり、名前を指定すればどれでも探せる。価格は元のジェムの4倍）だけで、商人や燼火の炉には並びません。数値は `Data.awaken()` が元のジェムから計算します（`Data.AWAKE_*`）。
- **ジェムレベル**：スキルジェムとサポートジェム（覚醒ジェムも）は Lv 1〜20。スキルバーに付けたスキルと、そのスロットで有効なサポートジェムは、敵を倒してキャラクターが得るのと同じ経験値を得てレベルが上がります（同じジェムを2つのスロットにリンクしていても1回分）。ジェムLvが1上がるごとに必要レベルが2上がり（覚醒ジェムは自分の高い必要レベルから）、キャラクターが次のジェムLvの必要レベルに届くまでは経験値が満タンのまま待ちます。サポートジェムは利点が1レベルごとに3%伸び（投射物数などの個数は変わらず、ダメージが利点でないものはダメージ +1%/Lv）、スキルジェムはダメージ +4%/Lv（強化・オーラの効果 +1.5%/Lv）。K の画面ではスロットとジェム一覧に Lv が、スロットの下に経験値のバーが、ソケットのジェムの右下に Lv が出て、ツールチップにジェムLv・伸び・経験値・次のLvに必要なキャラクターレベルが出ます。ドロップと商人のジェムは Lv 1、取引所はほとんどが Lv 1 で、ジェムの検索では「ジェムLv 以上」を指定できます（Lv が高いほど高価。持っているジェムは、より高い Lv の出品を買うとその Lv に入れ替わる）。経験値はセーブの `gem_xp` に残り、以前のセーブはすべて Lv 1 で読み込まれます（`Data.GEM_*`、`Player.gem_xp`）。
- **オーラ**：炉辺の守り火（Lv3）・熾火の鼓動（Lv5）・霜紗の帳（Lv8）・風詠みの讃歌（Lv11）・紅血の誓約（Lv14）の5種。スロットのキーを押すたびに発動／解除が切り替わり、発動中は自分と周囲9m以内の味方（ミニオン・トーテム）に効果が続きます。代わりに最大マナ（紅血の誓約は最大ライフ）の一定割合か固定値を「リザーブ」し、その分だけ使える上限が減ります。オーブの上部にリザーブ分がふたをされたように表示され、数字は残りの上限を示します。複数を重ねられますが、リザーブの合計が最大値を超える（ライフは1以上残らない）ときは発動できません。サポートジェムの「効率化」でリザーブが減り、「鼓舞」で効果が上がります（リザーブは増える）。装備やリンクの変更で足りなくなると、最後に発動したオーラから解除されます。発動状態はセーブされます。
- **エネルギー**：ジェムはそれぞれエネルギーを1〜3消費し、リンクの合計はエネルギー上限（2＋キャラクターレベル＋装備の「エネルギー上限」）まで。1スロットにつきリンクは最大6個です。装備を外して上限が下がると、スキルバーの後ろのスロットのリンクから無効になります。

- **パッシブツリー**：レベルが上がるたびに1ポイント（Lv N で N−1 ポイント）。全2000ノードの網目で、固定のシードから毎回同じ形に生成されます。中心の環から7層のクラスター（小ノードの環と、その中の注目ノードかジュエルの台座）が外へ広がり、同じ層の隣どうしと一つ内側の層が橋渡しのノードでつながります。最外周には24のキーストーン（大きな効果と大きな代償。例：灰鉄の心臓＝最大ライフ +40%・移動速度 -12%、星灯の叡智＝最大マナ +50%・スペルダメージ +30%（乗算）・攻撃ダメージ -40%（乗算））と6つのリングジュエルの大台座が並びます。円は 60° ずつ6つの区域に分かれ、各ベースキャラの区域（灰刃＝ライフ・アーマー・攻撃、燼紋＝スペル・マナ・元素、灯影＝クリティカル・速度・ミニオン）とその間の混ざる区域で、ノードの効果が変わります（注目ノードは外の層ほど強い）。取得済みのノードにつながったノードだけ取れ、離れたノードをクリックすると最短の道筋ごと取得します（ホバーで道筋と必要ポイントを表示）。取得済みのノードをクリック／右クリックで外せます（無料。外すとつながりが切れるノードは先の方から）。「すべて外す」で全部戻ります。ドラッグで移動、ホイールで拡大縮小、「起点へ」「全体」で表示を戻し、検索欄で名前や効果からノードを光らせます。画面に映るノードだけを描き、線はまとめて描くので、全体表示でも重くなりません。以前のタレントは廃止し、タレントを振っていたセーブは読み込み時にすべてパッシブポイントとして戻ります。
- **増加と乗算**：ダメージやライフの「+N%」はふつう「増加」で、同じ種類の増加はすべて足し合わせてから1回だけ掛かります（ダメージ +20% と +25% で +45%）。「（乗算）」と付く能力は増加とは別枠で、それぞれが単独で掛かります（ダメージ +20%（乗算）と +25%（乗算）で ×1.2×1.25＝+50%）。乗算はおもにキーストーン（灰嵐の狂奔・鬼哭の刃・星灯の叡智・燼の帳など。代償の「-N%（乗算）」もそのまま掛かる）、アセンダンシーのコアタレント（灼熱の拳・燼の狂奔・星喰み・虚無の潮）、特殊修飾子「猛威の紋」から得られ、種類は全体・攻撃・スペル・火炎・冷気・雷・混沌・ミニオン・最大ライフの9つ。ステータス画面とインベントリに全体／攻撃／スペルの乗算の倍率が出ます。乗算で上がる火力に合わせて、敵のライフはエリアレベルごとに +1.2%、ダメージは +0.6% ずつ追加で上乗せされます（Lv50 でライフ約1.6倍・ダメージ約1.3倍）。
- **ジュエルとリングジュエル**：敵が落とします（ボス60%、エリート12%、通常0.6%）。パッシブツリーの画面の右側で管理し（キャラクターごとに40個まで。要らないものは砕いて灰燼の欠片に）、選んでから台座ノードをクリックするとはめます（まだ取っていない台座なら道筋ごと取得）。右クリックで外せます。
  - **ジュエル**：ひし形の「ジュエルの台座」にはめ、その台座を取得している間だけ能力が効きます。ベースは3種（灰・燼・影。それぞれ固定の能力つき）、レア度はノーマル・マジック・レアで、装備と同じカレンシーでクラフトします（変容の結晶でマジック、昇華の焔でレア、混沌の残光で作り直し、鍛錬の砥石で1つ追加、浄化の雫でノーマルに、神秘の核で数値の振り直し）。台座に入れたままではクラフトできません。
  - **ユニークのジュエルとリングジュエル**：ジュエル4種とリングジュエル3種。敵が落とすものの2%がユニークで、取引所ではユニーク名で探せます（商人には並びません）。能力は固定でクラフトできず、固有効果は取得した台座に入っている間だけ効きます。ジュエルが一杯でも自動では砕かれず、手で砕くときは確認が入ります。
  - **リングジュエル**：最外周の六角の「リングジュエルの大台座」にはめると、その先にリングジュエル自身のノードの環が伸びます。大きさ（小リングジュエル＝小ノード4、リングジュエル＝6、大リングジュエル＝8とジュエルの小台座1）と主題（刃鳴り・鉄壁・業火・霜夜・雷鳴・灯霊・命脈・秘儀の8種。小ノードの効果）と、オプションのように付く注目ノード（主題ごとに4種から、マジック1・レアは上限まで）と環の強さ（小ノードの値の上乗せ）で環の中身が決まります。伸びた環のノードはふつうのノードと同じく取得・取り外しでき、セーブにも残ります。リングジュエルを外すと環のノードに振ったポイントは戻ります。クラフトはジュエルと同じカレンシーで、混沌の残光は主題と注目ノード、鍛錬の砥石は注目ノードの追加、神秘の核は環の強さを振り直します。
- **ベースキャラ**：キャラクター作成時に3つから選びます。初期能力の傾向・初期装備・初期スキルバー・鎧の色が変わり、選べるアセンダンシーはそのベースキャラの3つだけです。
  - **灰刃の剣士**（最大ライフ +30・アーマー +10・攻撃ダメージ +10%／最大マナ -10、片手剣と盾、紺と銀の鎧）：剣聖／鉄燼の城塞（アーマー・ライフ回復・被ダメージ軽減）／血焔の闘士（火炎をまとう攻撃・撃破時回復）
  - **燼紋の術士**（最大マナ +30・詠唱速度 +8%・スペルダメージ +10%／最大ライフ -10、ルーンの杖、紅と金の鎧にマント）：焔王／霜雷の巫女／星砂の賢者（スペル全般・マナ・エネルギー上限）
  - **灯影の導き手**（移動速度 +6%・攻撃速度 +5%・クリティカル率 +2%・ミニオンのダメージ +15%、短剣と盾、緑と青銅の鎧にマント）：冥導師／影走りの狩人（攻撃・移動・クリティカル）／蝕月の呪詠者（呪い・混沌・吸収）
  - ベースキャラができる前のキャラクターは、選んでいたアセンダンシーの属するベースキャラに、未選択なら灰刃の剣士になります（装備やスキルはそのまま）。シーズン終了でスタンダードへ移ってもベースキャラは変わりません。
- **アセンダンシー**：ベースキャラごとの3系統の血統から1つを選びます（最初の選択は無料）。2レベルごとに1ポイント（Lv2 で最初の1点）得て、血統ごとの4つのマイナーノード（各最大3ランク）に振ります。振った合計が 2・5・8 に達するとコアタレントの段が順に開放され、各段で1つを選びます（コアの選択はいつでも無料で入れ替え可能）。血統の選び直しには振ったポイント×25 の灰燼の欠片がかかります。
  - **ユニーク・アセンダンシー**：最後の段には血統ごとに金色の3つ目の選択肢があります。それだけの効果は控えめですが、対応するユニークと組み合わせると大きな力を発揮します。
- **組み合わせ**：必要なものがそろっている間だけ効く追加の能力です（全12種）。ユニーク・アセンダンシーと対応するユニーク装備の組み合わせが血統ごとに1つ、ベースキャラごとにユニークのジュエルまたはリングジュエルとユニークのルーンタブレットの組み合わせが1つあります。ユニークのツールチップに相手と効果が書かれ、発動中は状態アイコンに並びます。
- **ルートフィルタ**：レア度ごとに「拾う／拾って売却／非表示（落ちた瞬間に売却）」を選べ、部位ごとに拾わない設定もできます（レジェンドは除く）。希少度「神話」のユニークは設定にかかわらず必ず拾います。
- **灯り狐**：いつもそばにいるペット。近くに落ちたカレンシーやアイテムを拾ってきます。ボスを倒してポータルに入ると、周りに残ったアイテムもまとめて回収します。
- **遠征図とマップ**：マップは **5属性×10＝50種**（物理＝朽ちた地下墓所、火炎＝溶岩の洞窟、冷気＝凍てつく聖堂、雷＝雷鳴の遺跡、混沌＝腐蝕の沼窟）で、開放の順番はなく、どのマップも同じ Tier 制で、**Tier に上限はありません**（数値が壊れないよう T9999 で頭打ち）。入るには**地図**（◈ 入場アイテム。「<マップ名>の地図（T3）」のようにマップと Tier が決まっている）が1枚要り、出撃で消費します。**Tier が難度を決め、エリアレベル＝Tier** です。さらに Tier ごとに敵のライフとダメージが倍率で伸び、その倍率の1段は深いほど大きくなります（T2〜5 は ×1.04 ずつ、T6〜15 は ×1.08、T16〜30 は ×1.12、T31〜 は ×1.15。ダメージはその 0.6 乗）。代わりにアイテム数量（Tier ごとに +2.5%）・レア度（+2%）・灰燼の欠片が増えます。一覧は `docs/db/maps.md`。マップ効果の数も Tier で増え（T1〜2 なし、T3〜5 0〜1、T6〜10 1〜2、T11〜 2〜3。地図ごとに抽選され、羅針の欠片で振り直せる）、隠れ家のレベルは踏破した最高 Tier になります。地図は**ボスが必ず1枚（半分の確率で2枚）**、エリートが10%、通常の敵が0.8%で落とし、50種からランダムで Tier はそのマップの前後（ボスは +1 が35%・+2 が10%、通常の敵は -1 も出る）。遠征図の祭壇では選んだマップの T1 の地図を灰燼の欠片で買えるので、地図が尽きても詰まりません。持っている地図は祭壇で価値の40%で売れ、取引所の出品検索（「遠征地図」）でも Tier を指定して買えます。地図の価値はその Tier の1回の稼ぎに見合い、深い Tier ほどそれ以上に高くなります。新しいキャラクターは各属性の最初のマップの T1 を1枚ずつ持って始まり、旧遠征図のセーブは最深の踏破を最高 Tier にして各属性の地図をその Tier で受け取ります。マップは**レイアウトが固定**で、部屋はマップごとに手で配置したルート（一本道・S字・環と中心・十字・階段・雷文・8の字・梯子・格子・砂時計・照準・円渦・星・魚の骨・錨・鉤爪・腸・二重アーチなど50通りの形）の上に並び、道もその形どおりにつながります。部屋の大きさ・壁の崩れ・柱・床・小物はマップごとの固定シードで決まるので、毎回同じ見た目と道筋になります（敵の配置とドロップは毎回変わる）。最初の点が入口、本道の終点がボス部屋で、枝道や輪は寄り道・別ルートです。遠征図の画面は属性ごとの行に10マップずつルートの形を描いて並べ、所持している地図の数と最低 Tier、踏破済みの印を表示します。属性ごとに出やすい敵も変わります（火炎はインプとブルート、冷気は弓兵と呪術師など）。
- **ボス**：マップの属性でボスが変わります（物理＝深淵の番人、火炎＝灼熱の巨像、冷気＝凍嵐の魔女、雷＝雷鳴の王、混沌＝腐蝕の巨像）。巨像は炎の跡を残す突進と隕石、魔女は瞬間移動と移動速度を下げる冷気を使い、雷鳴の王は魔女の、腐蝕の巨像は巨像の技をそれぞれの色で使います。どれもライフ半分で激昂します。
- **シーズン**：開催期間は `scripts/data.gd` の `SEASONS`（UTC の日付）で決まります。シーズン中だけそのシーズンのキャラクターを作成できます。シーズンが終わると、次の起動時にそのシーズンのキャラクターはスタンダードへ移行し（選択画面に「元シーズン」と表示）、シーズンのスタッシュはスタンダードのスタッシュに「シーズン名 1, 2…」のタブとして追加されます。開発中は `-- --date=2027-02-01` のように日付を偽装して終了を試せます。
- **燼火の祭壇**：マップの部屋のいくつかに眠っている祭壇（入るとメッセージで数が分かる）。近くで B かクリックすると「誓約」を選んで点火でき、祭壇の周りに燼に触れた敵が3つの波で押し寄せ、最後の波には精鋭の「燼魂の守り手」が混ざります。すべて倒すと専用の通貨「燼晶」（❖）とアイテム・灰燼の欠片が祭壇から湧き、燼に触れた敵も燼晶を落とすことがあります。誓約は 烈火（敵のライフ・ダメージ +40% → 燼晶 +60%・位階 +1）／群火（波 +1・守り手 +1 → 燼晶 +40%・アイテム +2）／灼刻（50秒以内に全滅させる。失敗すると報酬なし → アイテム +2・レア度 +150%・位階 +2）。祭壇を鎮めるたびに「燼火の位階」が上がり、2つ目の祭壇の出現率と燼晶の量が増え、誓約と交換品が開放されます。燼晶は隠れ家の「燼火の炉」でレア装備・混沌の残光・未入手のサポートジェム・神秘の核・レジェンド、次のマップの祭壇を2つ増やす「燼火の導標」と交換できます。燼晶・位階・導標はリーグ（各シーズン／スタンダード）ごとに共有で、シーズンが終わると燼晶と導標はスタンダードに加算され、位階は高いほうが残ります。
- **タブレット盤**（G）：ボスは倒されると必ず「ルーンタブレット」を1つ落とします。ルーンタブレットは1〜6マスのさまざまな形（全14種）で、半分は能力が1行刻まれた状態、残りは無地です。タブレット盤の6×6のマスにルーンタブレットを90度ずつ回して重ならないように置くと、盤に置いたルーンタブレットの能力だけが効きます（最大36マス）。能力の値はルーンタブレットのマス数とアイテムレベルで大きくなり、刻める行数もマス数で決まります（1〜2マス：1行、3〜4マス：2行、5〜6マス：3行）。盤の画面でルーンタブレットを選び、鍛錬の砥石で1行刻む・混沌の残光で刻み直す・神秘の核で数値を振り直すことができ、要らないルーンタブレットは砕いて灰燼の欠片にできます。ルーンタブレットはキャラクターごとに40個まで持てます。ボスが落とすルーンタブレットの5%はユニーク（全4種）で、能力は固定で刻めず、盤に置いている間だけ効きます。取引所ではユニーク名で探せ、一杯でも自動では砕かれません。
- **コンパス**：燼火で針を灯した真鍮の羅針盤で、マップの敵が落とします（ボス60%、エリート5%、通常0.4%。エリアレベルが高いほど上の階位が出やすい）。隠れ家の遠征図で地点を選び、出撃前に右側の欄で最大4つ（同じ系統は1つまで）はめると、そのマップ1回にだけ効果が加わり、マップに入ると燃え尽きます（クリックで外せば残ります）。系統は7つ×階位3つ：群呼（敵の群れの数と大きさ +20/35/50%）・精鋭（エリートの出現率 1.5/2/3倍）・蓄財（灰燼の欠片 +30/60/100%、カレンシーのドロップ 1.5/2/3倍）・刻碑（ボスのルーンタブレット +1/+1/+2、ジュエルのドロップ 1.5/2/3倍）・封紋（刻紋の封碑が 1/2/3 つ確定）・燼冠（ボスが「燼冠の」になりライフとダメージが上がり、アイテムを +2/+3/+5 多く落とす）・苛烈（敵のライフとダメージが上がり、アイテムレア度・数量・経験値が増える）。所持品とスタッシュ（リーグごと。クリックでまとめて、右クリックで1つ移す）で重ねて持て、ツールチップで Alt を押すと同じ系統の全階位の効果を出します。コンパスごとに価値（灰燼の欠片での基準値、`Charms.value`）があります。
- **特殊修飾子と刻紋の封碑**：マップの半分ほどに「刻紋の封碑」が1つ立っています（入るとメッセージで分かる）。近くで B かクリックすると封印が解け、エリートの「封碑の番人」が3体以上（エリアレベルで増える）現れ、番人が残っている間は封碑がプレイヤーの足元に刻紋の爆発を放ち続けます。番人をすべて倒すと、新しい通貨「刻紋の熾石」（✠）・レア装備・灰燼の欠片が出ます。刻紋の熾石はレアアイテムにだけ使え、オプションとは別枠の「特殊修飾子」（最大ライフ%・三界の属性ダメージ・攻撃と詠唱の速度・被ダメージ軽減・ミニオンの強化など9種）を1つ刻みます。もう一度使うと別の特殊修飾子に刻み直し、混沌の残光では消えず、浄化の雫で消えます。
- **取引所**：隠れ家の長机。相場はすべて混沌の残光建てで、マップを1つ踏破するごとに1ティック進みます。「出品検索」ページは最初は何も並んでおらず、種類（装備・ルーンタブレット・ジュエル・リングジュエル・コンパス・ジェム・カレンシー）、部位、レア度、ベース名、ユニーク名（名前の一部で候補が出る）、オプション（最大3つ、それぞれ最低値つき。装備は刻紋も）、アイテムレベル、価格の範囲を決めて「検索」を押すと、条件に合う出品が最大12件その場で作られます（同じ条件なら次のマップを踏破するか「出品を入れ替える」を押すまで同じ品）。価格は「品の価値 × 3 × 出品者の値付け（0.9〜1.25）× 条件の倍率」の混沌で、オプションを指定するほど、出にくいオプションほど、最低値が高いほど、希少度の高いユニークほど高くなります（買ってすぐ業者・商人に売ったり砕いたりしても損になります）。付かないオプションや届かない最低値など、合う品がありえない条件では理由が表示されます。「通貨」ページではクラフト通貨を成行・指値で売買し、「装備」ページではレア・ユニークを希望価格で出品（売れたら帰還時に通知、売れ残りは受け取り箱へ）したり、業者に即売りしたり、ほかの冒険者の出品を買ったりできます。装備の相場は能力値の出目・ユニークの人気・シーズンの流行（火炎・召喚などのタグ）で決まります。「買取依頼」ページでは NPC が求める条件の装備を納品すると報酬の混沌がもらえます。手数料は灰燼の欠片。詳しくは `docs/economy-design.md`。
- **燼藁のカカシ**（DPS 測定）：隠れ家の右下に立つ、燼の帯を巻いた藁の的。普通の敵と同じ処理でダメージを受けるので、スキル・サポートジェム・会心・燃焼／出血／毒・ミニオンとトーテム・呪い（被ダメージ増加）がすべて数えられます。動かず攻撃もせず、ライフは毎回全快して倒れず、経験値・ドロップ・回復薬の補充・撃破時の効果はありません。頭上の枠に直近5秒の DPS、最大 DPS、合計ダメージ・経過時間・平均 DPS、属性ごとの割合のバー、スキル（と持続ダメージ）ごとの内訳の上位4つが出ます。6秒ダメージを与えないか、近くで B／クリックすると計測が最初からやり直しになります。
- **マップ（オーバーレイ）**（M）：ゲーム画面の上に、いまいるマップの見取り図を半透明で重ねて表示します。プレイヤーを中心に、カメラと同じ向き（画面の上がマップの上）で描かれ、矢印がプレイヤーの位置と向きです。マップは歩いた周り（半径約17m）だけが少しずつ見えるようになり、まだ行っていない場所は表示されません。見つけた場所には印が付きます（ボス撃破後の出口ポータル、遠征図の祭壇・商人・スタッシュ・取引所・燼火の炉・燼藁のカカシ、燼火の祭壇、刻紋の封碑）。探索の状態はマップごとで、新しいマップに入る（同じマップにもう一度入る・隠れ家に戻る）と最初からになります。一時停止メニュー（Esc）の「オプション」で**透過率**（0〜90%）と**拡大率**（50〜300%）を変えられ、動かしたその場で反映されます。どちらもキー設定と同じ `user://emberfall_settings.cfg` の `[options]` に保存され、起動時に読み込まれます。
- **被ダメージ演出の強さ**：一時停止メニュー（Esc）の「オプション」で、プレイヤーが攻撃を受けたときの演出の強さを 0〜100%（初期値 50%）で変えられます。演出は画面の縁だけを赤くする**ビネット**（中央はかからない）・カメラの揺れ・キャラが白く光る効果で、どれもこの割合に比例し、0% で消えます（ダメージの数字と左下のライフのオーブは常に表示）。100% でも以前より控えめです（以前は画面全体に 0.3 の赤・揺れ 4・0.15 秒の白い光 0.55 → 縁の赤 0.3・揺れ 2・0.1 秒の白い光 0.4）。連続で攻撃を受けても、演出は 0.35 秒に1回までしか出ないので画面が光りっぱなしになりません。ライフ30%未満の赤い脈動も、以前の画面全体 0.04〜0.2・約1秒周期から、縁だけ 0.03〜0.09（100% のとき）・2.4 秒周期のゆっくりした明滅にしました。設定はマップと同じ `[options]` に保存されます。
- **スタッシュ**：隠れ家の宝箱。リーグ（各シーズン／スタンダード）ごとに共有で、同じリーグのキャラクター同士でアイテムを受け渡せます。1タブ48マス×4タブ。
- **セーブ**：全キャラクターとスタッシュを `user://emberfall_profiles.json` に保存します。以前の `emberfall_save.json` は初回起動時にスタンダードのキャラクター「放浪者」として取り込まれ、元のファイルはバックアップとしてそのまま残ります。
- **ユニーク（レジェンド）**：1015種。部位と武器種ごとに散らばり、固定の能力値（中には代償となるマイナス値も）と、スキルの挙動やビルドの軸を変える効果（アセンダンシーの核タレントや「クリティカルを捨ててダメージ +45%」などの固有効果）を持ちます。最上位の希少度「神話」の6種は比重が至宝の10分の1で、敵のドロップと取引所でのみ手に入り（商人・燼火の炉・ほかの冒険者の出品には並びません）、乗算のダメージやライフで通常のユニークを大きく上回ります。
- **遠征パッシブ**：50マップそれぞれの初踏破ごとに1ポイント（旧遠征図の残り火の深淵の踏破ぶんも残ります）。財宝・征服・探索の3系統で、上から順に開放されます。ポイントは灰燼の欠片で振り直せます。
- **状態アイコン**：画面左上の情報行の下に、小さなアイコンが1列に並びます。召喚中のミニオン（スキルごと）・トーテム・罠は右下に「いま／最大」の数、発動中のオーラは自分の色の枠、強化スキルは残り秒数、アセンダンシーの重ね掛け強化（戦意高揚など）は重ねた数を表示し、時間制のものは時計回りに暗くなって残り時間を示します。マウスを乗せると名前と効果（オーラは範囲とリザーブ、ミニオンは数と最短の残り時間）が出ます。アイコンは召喚・消滅・オーラの切り替え・強化の付与と終了のときだけ組み直されます。
- **ステータス画面のキャラクター画像**：C の画面の左に、いま装備している武器を持ったヒロインが表示されます。「画像を読み込む」で好きな画像（PNG・JPG・WebP）に差し替えられ、「3D表示に戻す」で元に戻ります。読み込んだ画像はユーザーデータ（Windows では `%APPDATA%\Godot\app_userdata\Emberfall\portrait.png`）にコピーされるので、リポジトリには入りません。

## 構成
- `scripts/main.gd` — ゲームループ、ダンジョンの3D化、スキル・敵AI・戦闘、カメラ
- `scripts/dungeon.gd` — 部屋と通路のダンジョン生成、経路探索（ゲームの計算は平面グリッド上）
- `scripts/player.gd` / `enemy.gd` / `actor.gd` — キャラクターと仮モデル
- `scripts/heroine.gd` — 操作キャラの見た目（騎士の体にローグの顔、ピンクの髪・アホ毛・丸メガネ、ベースキャラごとの鎧の色とマント）
- `scripts/hud.gd` — HUD（オーブ、スキルバー、体力バー、ダメージ数字、死亡画面）
- `scripts/status_bar.gd` — 左上の状態アイコン（ミニオン・トーテム・罠の数、オーラ、強化。シグナルで変化したときだけ組み直し、アイコンは使い回し）
- `scripts/items.gd` / `inventory_ui.gd` / `item_slot.gd` — アイテム生成・クラフト・インベントリ画面
- `scripts/mod_range.gd` — Alt を押している間のツールチップの数値の範囲（アフィックス・ユニーク・特殊修飾子・ジュエル・リングジュエル・ルーンタブレットの定義とアイテムレベルから、ロールと同じ式で求める）
- `scripts/item_icon.gd` — 装備のベースごとのアイコン（ベクター描画）
- `scripts/skill_icon.gd` — スキルとサポートジェムのアイコン（ベクター描画。属性色の枠＋スキルごとの発光モチーフ、ジェムは対象でカットが変わる）
- `scripts/maps.gd` — 50マップ（属性・名前・ルートの形）と地図（入場アイテム）のキー・Tier・マップ効果の数・ドロップの抽選・価値
- `scripts/atlas.gd` / `atlas_ui.gd` — 遠征図の進行状況（所持している地図・踏破・最高 Tier・地図ごとのマップ効果）と画面（50マップのルートの形の一覧）
- `scripts/shop_ui.gd` — 隠れ家の商人（装備・ルーンタブレット・ジュエルとリングジュエル・コンパス・ジェム・カレンシーのタブ、装備の絞り込み）
