# Emberfall (Godot 4)

ブラウザ版プロトタイプを Godot 4 に移植したプロジェクトです（ブラウザ版はリポジトリから外し、手元の `OLD/` にだけ残しています）。

## 開き方
1. Godot 4.7 を起動し、「インポート」でこのフォルダの `project.godot` を選ぶ
2. F5（プロジェクトを実行）で遊べます

## 操作
| キー | 動作 |
|---|---|
| WASD | 移動（画面の上下左右） |
| 左クリック / 右クリック / Q / E / R / Space | スキルバーのスキル（初期：斬撃・ファイアボール・フロストノヴァ・チェインライトニング・メテオ・シャドウダッシュ） |
| F | 回復薬 |
| I / Tab | インベントリ |
| K | スキルとサポートジェム（スキルバーのスロットをクリックしても開く） |
| T | パッシブツリー |
| U | アセンダンシー |
| C | ステータス |
| L | ルートフィルタ |
| P | 遠征パッシブ（遠征図の画面からも開ける） |
| G | 石板盤 |
| B / 左クリック | 隠れ家で商人・遠征図の祭壇・スタッシュを開く、燼藁のカカシの計測をリセット（近くで B） |
| O | キー設定 |
| Esc | 開いている画面を閉じる。何も開いていなければ一時停止（マップの放棄はここから） |

上は既定のキーです。**キー設定**（O、または一時停止メニューの「キー設定」）で、Esc 以外のすべての操作を好きなキーやマウスボタン（左・右・中・マウス4/5）に割り当て直せます。割り当て欄をクリックしてから押したキーが入り、右クリックで解除、各操作に2つまで割り当てられます。ほかの操作で使っているキーを選ぶと、その操作と入れ替わります（どう入れ替わったかは画面の下に表示）。「既定に戻す」ですべて元に戻ります。割り当てはキャラクターではなくユーザー設定として `user://emberfall_settings.cfg`（Windows では `%APPDATA%\Godotpp_userdata\Emberfall\`）に保存され、起動時に読み込まれます。スキルバーやヒント・メッセージに出るキーの表記も割り当てに合わせて変わります。

起動するとキャラクター選択画面が開きます。キャラクターは「シーズン」か「スタンダード」のどちらかで作成し、一時停止メニューからいつでも選択画面に戻れます。ゲームは隠れ家から始まります。遠征図の祭壇でマップを選んで出撃し、ボスを倒してポータルに入ると踏破となり、隣のマップが開放されて隠れ家に戻ります。商人は隠れ家にだけいて、踏破のたびに品揃えが入れ替わります。

スキルは全65種。最初に使えるのはベースキャラの初期スキルバーの6つだけで、ほかは**スキルジェム**として敵のドロップか商人で手に入れます。スキルとサポートジェムにはそれぞれ**必要レベル**（スキル Lv1〜18、サポート Lv1〜16）があり、持っていてもそのレベルになるまではスロットに付けたりリンクしたりできません（K の画面ではタグで絞り込め、未入手・レベル不足のものにはその旨と必要レベルが出ます）。ジェムのドロップはそのエリアのレベル＋2 までのものが中心で、商人には「キャラクターのレベル＋3」までの未入手のジェムが並びます（値段は必要レベルで上がる）。持っているジェムをまた拾うと灰燼の欠片になります。スキルジェム導入前のキャラクターは、そのレベルで習得済みだったスキルをすべて持った状態で読み込まれます。手に入れたスキルは6つのスロットに好きに付け替えられます。スキルは「前方を薙ぐ」「投射物」「カーソル位置の範囲」「持続範囲」「強化」「呪い」「召喚」「移動」などの効果ブロックを組み合わせたデータで定義されています。移動スキル（シャドウダッシュ・瞬歩・跳躍斬）以外にはクールダウンがなく、連射の速さは攻撃速度・詠唱速度とマナで決まります。

サポートジェム（全60種。威力増幅・多重投射・トーテム化・軍勢・罠化・残響など）も敵のドロップか商人で手に入り、スロットにリンクするとそのスキルの挙動が変わります。ジェムはスキルのタグに合うものだけが効きます。骸骨とトーテムは敵からも狙われます。
- **オーラ**：炉辺の守り火（Lv3）・熾火の鼓動（Lv5）・霜紗の帳（Lv8）・風詠みの讃歌（Lv11）・紅血の誓約（Lv14）の5種。スロットのキーを押すたびに発動／解除が切り替わり、発動中は自分と周囲9m以内の味方（ミニオン・トーテム）に効果が続きます。代わりに最大マナ（紅血の誓約は最大ライフ）の一定割合か固定値を「リザーブ」し、その分だけ使える上限が減ります。オーブの上部にリザーブ分がふたをされたように表示され、数字は残りの上限を示します。複数を重ねられますが、リザーブの合計が最大値を超える（ライフは1以上残らない）ときは発動できません。サポートジェムの「効率化」でリザーブが減り、「鼓舞」で効果が上がります（リザーブは増える）。装備やリンクの変更で足りなくなると、最後に発動したオーラから解除されます。発動状態はセーブされます。
- **エネルギー**：ジェムはそれぞれエネルギーを1〜3消費し、リンクの合計はエネルギー上限（2＋キャラクターレベル＋装備の「エネルギー上限」）まで。1スロットにつきリンクは最大6個です。装備を外して上限が下がると、スキルバーの後ろのスロットのリンクから無効になります。

- **パッシブツリー**：レベルが上がるたびに1ポイント（Lv N で N−1 ポイント）。全2000ノードの網目で、固定のシードから毎回同じ形に生成されます。中心の環から7層のクラスター（小ノードの環と、その中の注目ノードか燈晶の台座）が外へ広がり、同じ層の隣どうしと一つ内側の層が橋渡しのノードでつながります。最外周には24のキーストーン（大きな効果と大きな代償。例：灰鉄の心臓＝最大ライフ +40%・移動速度 -12%、星灯の叡智＝最大マナ +50%・スペルダメージ +30%（乗算）・攻撃ダメージ -40%（乗算））と6つの環晶の大台座が並びます。円は 60° ずつ6つの区域に分かれ、各ベースキャラの区域（灰刃＝ライフ・アーマー・攻撃、燼紋＝スペル・マナ・元素、灯影＝クリティカル・速度・ミニオン）とその間の混ざる区域で、ノードの効果が変わります（注目ノードは外の層ほど強い）。取得済みのノードにつながったノードだけ取れ、離れたノードをクリックすると最短の道筋ごと取得します（ホバーで道筋と必要ポイントを表示）。取得済みのノードをクリック／右クリックで外せます（無料。外すとつながりが切れるノードは先の方から）。「すべて外す」で全部戻ります。ドラッグで移動、ホイールで拡大縮小、「起点へ」「全体」で表示を戻し、検索欄で名前や効果からノードを光らせます。画面に映るノードだけを描き、線はまとめて描くので、全体表示でも重くなりません。以前のタレントは廃止し、タレントを振っていたセーブは読み込み時にすべてパッシブポイントとして戻ります。
- **増加と乗算**：ダメージやライフの「+N%」はふつう「増加」で、同じ種類の増加はすべて足し合わせてから1回だけ掛かります（ダメージ +20% と +25% で +45%）。「（乗算）」と付く能力は増加とは別枠で、それぞれが単独で掛かります（ダメージ +20%（乗算）と +25%（乗算）で ×1.2×1.25＝+50%）。乗算はおもにキーストーン（灰嵐の狂奔・鬼哭の刃・星灯の叡智・燼の帳など。代償の「-N%（乗算）」もそのまま掛かる）、アセンダンシーのコアタレント（灼熱の拳・燼の狂奔・星喰み・虚無の潮）、特殊修飾子「猛威の紋」から得られ、種類は全体・攻撃・スペル・火炎・冷気・雷・混沌・ミニオン・最大ライフの9つ。ステータス画面とインベントリに全体／攻撃／スペルの乗算の倍率が出ます。乗算で上がる火力に合わせて、敵のライフはエリアレベルごとに +1.2%、ダメージは +0.6% ずつ追加で上乗せされます（Lv50 でライフ約1.6倍・ダメージ約1.3倍）。
- **ジュエル（燈晶と環晶）**：敵が落とします（ボス60%、エリート12%、通常0.6%）。パッシブツリーの画面の右側で管理し（キャラクターごとに40個まで。要らないものは砕いて灰燼の欠片に）、選んでから台座ノードをクリックするとはめます（まだ取っていない台座なら道筋ごと取得）。右クリックで外せます。
  - **燈晶**：ひし形の「燈晶の台座」にはめ、その台座を取得している間だけ能力が効きます。ベースは3種（灰・燼・影。それぞれ固定の能力つき）、レア度はノーマル・マジック・レアで、装備と同じカレンシーでクラフトします（変容の結晶でマジック、昇華の焔でレア、混沌の残光で作り直し、鍛錬の砥石で1つ追加、浄化の雫でノーマルに、神秘の核で数値の振り直し）。台座に入れたままではクラフトできません。
  - **環晶**：最外周の六角の「環晶の大台座」にはめると、その先に環晶自身のノードの環が伸びます。大きさ（小環晶＝小ノード4、環晶＝6、大環晶＝8と燈晶の小台座1）と主題（刃鳴り・鉄壁・業火・霜夜・雷鳴・灯霊・命脈・秘儀の8種。小ノードの効果）と、オプションのように付く注目ノード（主題ごとに4種から、マジック1・レアは上限まで）と環の強さ（小ノードの値の上乗せ）で環の中身が決まります。伸びた環のノードはふつうのノードと同じく取得・取り外しでき、セーブにも残ります。環晶を外すと環のノードに振ったポイントは戻ります。クラフトは燈晶と同じカレンシーで、混沌の残光は主題と注目ノード、鍛錬の砥石は注目ノードの追加、神秘の核は環の強さを振り直します。
- **ベースキャラ**：キャラクター作成時に3つから選びます。初期能力の傾向・初期装備・初期スキルバー・鎧の色が変わり、選べるアセンダンシーはそのベースキャラの3つだけです。
  - **灰刃の剣士**（最大ライフ +30・アーマー +10・攻撃ダメージ +10%／最大マナ -10、片手剣と盾、紺と銀の鎧）：剣聖／鉄燼の城塞（アーマー・ライフ回復・被ダメージ軽減）／血焔の闘士（火炎をまとう攻撃・撃破時回復）
  - **燼紋の術士**（最大マナ +30・詠唱速度 +8%・スペルダメージ +10%／最大ライフ -10、ルーンの杖、紅と金の鎧にマント）：焔王／霜雷の巫女／星砂の賢者（スペル全般・マナ・エネルギー上限）
  - **灯影の導き手**（移動速度 +6%・攻撃速度 +5%・クリティカル率 +2%・ミニオンのダメージ +15%、短剣と盾、緑と青銅の鎧にマント）：冥導師／影走りの狩人（攻撃・移動・クリティカル）／蝕月の呪詠者（呪い・混沌・吸収）
  - ベースキャラができる前のキャラクターは、選んでいたアセンダンシーの属するベースキャラに、未選択なら灰刃の剣士になります（装備やスキルはそのまま）。シーズン終了でスタンダードへ移ってもベースキャラは変わりません。
- **アセンダンシー**：ベースキャラごとの3系統の血統から1つを選びます（最初の選択は無料）。2レベルごとに1ポイント（Lv2 で最初の1点）得て、血統ごとの4つのマイナーノード（各最大3ランク）に振ります。振った合計が 2・5・8 に達するとコアタレントの段が順に開放され、各段で2つのうち1つを選びます（コアの選択はいつでも無料で入れ替え可能）。血統の選び直しには振ったポイント×25 の灰燼の欠片がかかります。
- **ルートフィルタ**：レア度ごとに「拾う／拾って売却／非表示（落ちた瞬間に売却）」を選べ、部位ごとに拾わない設定もできます（レジェンドは除く）。
- **灯り狐**：いつもそばにいるペット。近くに落ちたカレンシーやアイテムを拾ってきます。ボスを倒してポータルに入ると、周りに残ったアイテムもまとめて回収します。
- **ボス**：マップの地形でボスが変わります（地下墓所＝深淵の番人、溶岩の洞窟＝灼熱の巨像、凍てつく聖堂＝凍嵐の魔女）。巨像は炎の跡を残す突進と隕石、魔女は瞬間移動と移動速度を下げる冷気を使い、どちらもライフ半分で激昂します。
- **シーズン**：開催期間は `scripts/data.gd` の `SEASONS`（UTC の日付）で決まります。シーズン中だけそのシーズンのキャラクターを作成できます。シーズンが終わると、次の起動時にそのシーズンのキャラクターはスタンダードへ移行し（選択画面に「元シーズン」と表示）、シーズンのスタッシュはスタンダードのスタッシュに「シーズン名 1, 2…」のタブとして追加されます。開発中は `-- --date=2027-02-01` のように日付を偽装して終了を試せます。
- **燼火の祭壇**：マップの部屋のいくつかに眠っている祭壇（入るとメッセージで数が分かる）。近くで B かクリックすると「誓約」を選んで点火でき、祭壇の周りに燼に触れた敵が3つの波で押し寄せ、最後の波には精鋭の「燼魂の守り手」が混ざります。すべて倒すと専用の通貨「燼晶」（❖）とアイテム・灰燼の欠片が祭壇から湧き、燼に触れた敵も燼晶を落とすことがあります。誓約は 烈火（敵のライフ・ダメージ +40% → 燼晶 +60%・位階 +1）／群火（波 +1・守り手 +1 → 燼晶 +40%・アイテム +2）／灼刻（50秒以内に全滅させる。失敗すると報酬なし → アイテム +2・レア度 +150%・位階 +2）。祭壇を鎮めるたびに「燼火の位階」が上がり、2つ目の祭壇の出現率と燼晶の量が増え、誓約と交換品が開放されます。燼晶は隠れ家の「燼火の炉」でレア装備・混沌の残光・未入手のサポートジェム・神秘の核・レジェンド、次のマップの祭壇を2つ増やす「燼火の導標」と交換できます。燼晶・位階・導標はリーグ（各シーズン／スタンダード）ごとに共有で、シーズンが終わると燼晶と導標はスタンダードに加算され、位階は高いほうが残ります。
- **石板盤**（G）：ボスは倒されると必ず「石板」を1つ落とします。石板は1〜6マスのさまざまな形（全14種）で、半分は能力が1行刻まれた状態、残りは無地です。石板盤の6×6のマスに石板を90度ずつ回して重ならないように置くと、盤に置いた石板の能力だけが効きます（最大36マス）。能力の値は石板のマス数とアイテムレベルで大きくなり、刻める行数もマス数で決まります（1〜2マス：1行、3〜4マス：2行、5〜6マス：3行）。盤の画面で石板を選び、鍛錬の砥石で1行刻む・混沌の残光で刻み直す・神秘の核で数値を振り直すことができ、要らない石板は砕いて灰燼の欠片にできます。石板はキャラクターごとに40個まで持てます。
- **特殊修飾子と刻紋の封碑**：マップの半分ほどに「刻紋の封碑」が1つ立っています（入るとメッセージで分かる）。近くで B かクリックすると封印が解け、エリートの「封碑の番人」が3体以上（エリアレベルで増える）現れ、番人が残っている間は封碑がプレイヤーの足元に刻紋の爆発を放ち続けます。番人をすべて倒すと、新しい通貨「刻紋の熾石」（✠）・レア装備・灰燼の欠片が出ます。刻紋の熾石はレアアイテムにだけ使え、オプションとは別枠の「特殊修飾子」（最大ライフ%・三界の属性ダメージ・攻撃と詠唱の速度・被ダメージ軽減・ミニオンの強化など9種）を1つ刻みます。もう一度使うと別の特殊修飾子に刻み直し、混沌の残光では消えず、浄化の雫で消えます。
- **取引所**：隠れ家の長机。相場はすべて混沌の残光建てで、マップを1つ踏破するごとに1ティック進みます。「通貨」ページではクラフト通貨を成行・指値で売買し、「装備」ページではレア・ユニークを希望価格で出品（売れたら帰還時に通知、売れ残りは受け取り箱へ）したり、業者に即売りしたり、ほかの冒険者の出品を買ったりできます。装備の相場は能力値の出目・ユニークの人気・シーズンの流行（火炎・召喚などのタグ）で決まります。「買取依頼」ページでは NPC が求める条件の装備を納品すると報酬の混沌がもらえます。手数料は灰燼の欠片。詳しくは `docs/economy-design.md`。
- **燼藁のカカシ**（DPS 測定）：隠れ家の右下に立つ、燼の帯を巻いた藁の的。普通の敵と同じ処理でダメージを受けるので、スキル・サポートジェム・会心・燃焼／出血／毒・ミニオンとトーテム・呪い（被ダメージ増加）がすべて数えられます。動かず攻撃もせず、ライフは毎回全快して倒れず、経験値・ドロップ・回復薬の補充・撃破時の効果はありません。頭上の枠に直近5秒の DPS、最大 DPS、合計ダメージ・経過時間・平均 DPS、属性ごとの割合のバー、スキル（と持続ダメージ）ごとの内訳の上位4つが出ます。6秒ダメージを与えないか、近くで B／クリックすると計測が最初からやり直しになります。
- **スタッシュ**：隠れ家の宝箱。リーグ（各シーズン／スタンダード）ごとに共有で、同じリーグのキャラクター同士でアイテムを受け渡せます。1タブ48マス×4タブ。
- **セーブ**：全キャラクターとスタッシュを `user://emberfall_profiles.json` に保存します。以前の `emberfall_save.json` は初回起動時にスタンダードのキャラクター「放浪者」として取り込まれ、元のファイルはバックアップとしてそのまま残ります。
- **ユニーク（レジェンド）**：1000種。部位と武器種ごとに散らばり、固定の能力値（中には代償となるマイナス値も）と、スキルの挙動やビルドの軸を変える効果（アセンダンシーの核タレントや「クリティカルを捨ててダメージ +45%」などの固有効果）を持ちます。
- **遠征パッシブ**：初踏破と残り火の深淵の踏破ごとに1ポイント。財宝・征服・探索の3系統で、上から順に開放されます。ポイントは灰燼の欠片で振り直せます。
- **ステータス画面のキャラクター画像**：C の画面の左に、いま装備している武器を持ったヒロインが表示されます。「画像を読み込む」で好きな画像（PNG・JPG・WebP）に差し替えられ、「3D表示に戻す」で元に戻ります。読み込んだ画像はユーザーデータ（Windows では `%APPDATA%\Godot\app_userdata\Emberfall\portrait.png`）にコピーされるので、リポジトリには入りません。

## データ資料
ユニーク・レア装備（ベースとオプション）・ベースキャラとアセンダンシー・パッシブツリー（全2000ノード）・ジュエル（燈晶と環晶）・スキルとサポートジェムの一覧を、ゲームのデータから自動生成して [`docs/db/`](../docs/db/README.md) に置いています（Markdown のページと、全ページを検索できる `docs/db/index.html`）。データを変えたら書き出し直してください（`tools/run_check.gd` は資料が古いと失敗します）:
```
Godot_v4.7.2-stable_win64.exe --headless --path . -s tools/gen_docs.gd
```

## 開発用

各項目は `SMOKE <項目> ...` の行に値を出し、期待どおりでないものは `SMOKE FAIL <項目> <条件>` と出ます。最後に `SMOKE RESULT checks=<数> failed=<数> [...]` を出し、失敗が1つでもあれば終了コード 1 で終わります:
```
Godot_v4.7.2-stable_win64.exe --headless --path . -- --smoke
```

画面を1つだけ開いて確認する場合（セーブは読み書きしません）。`merchant` `device` `stash` `exchange`（市場日 6、注文1件と指値の売りを用意） `exchange_gear`（装備ページ。所持品のユニークを選んだところ） `exchange_requests`（買取依頼ページ） `skills` `talents`（パッシブツリー。Lv24で起点から注目ノード2つまで取得済み） `tree_all`（ツリー全体を表示） `jewels`（大環晶で環を伸ばし、燈晶を2つはめたところ） `jewel_craft`（ジュエルを選んでクラフトのボタンが出たところ） `ascend`（育成途中の霜雷の巫女） `ascend_pick`（血統の選択） `chars`（キャラクター選択・作成画面。サンプルのキャラクター3人つき） `status` `filter` `passives` が使えます。`colossus` `witch` では最初のマップでそのボスがすぐ横に出ます。`aura0`（オーラをスロットに並べただけ） `aura`（3秒後に4つ発動し5つ目は拒否） `aura_off`（さらに1つ解除）ではオーラとリザーブの表示を、`altar`（眠っている祭壇） `altar_vow`（誓約の選択） `altar_wave`（烈火の誓約で点火） `altar_reward`（全波を倒して報酬が出たところ） `forge`（隠れ家の燼火の炉）では燼火の祭壇を、`tablets`（石板を5つ置いて1つ選んだ石板盤） `tablets_full`（36マスを埋めた盤） `seal`（眠っている刻紋の封碑） `seal_open`（番人が出たところ） `brand_tip`（特殊修飾子付きのレア装備のツールチップ）では石板と特殊修飾子を、`dummy`（隠れ家の燼藁のカカシをスキルで叩き続けているところ）では DPS 計測を確かめられます。`--class=ashblade|sigil|lantern` を付けるとそのベースキャラ（初期装備つき）で開きます（`chars` では作成欄でそのベースキャラを選んだ状態）。`--shot=<パス>` を付けると4.5秒後の画面をPNGに保存して終了します:
```
Godot_v4.7.2-stable_win64.exe --path . -- --view=merchant
Godot_v4.7.2-stable_win64.exe --path . -- --view=colossus
```
